## 执行摘要

本文件是司南系统 (SINAN) 为采购**电子海图数据服务（ENC Service）**和**电子海图仪（ECDIS）设备**而编制的完整需求规格书，供厂商评估报价及技术方案应答。

SINAN 的海图服务模块（Chart Service，卷2第4章）在系统五层架构的基础设施层提供空间安全法则支撑，消费者包括：
- **VRO**（航次航线优化）：全程航线 UKC 预扫描、障碍物 Costmap 构建、TSS 合规检查
- **COLAV**（碰撞规避）：百万级/秒实时碰撞检测（O(1) 栅格寻址）
- **UKC**（动态搁浅预警）：10Hz 实时 Net_UKC 计算，三维前瞻扫描
- **BERTH**（智能靠泊）：港内高精度水深及泊位水底剖面

## 第 2 章　系统背景与采购驱动力

### 2.1　海图在 SINAN 架构中的关键位置

司南系统的海图服务层（SINAN-INFRA-SDD-001 §4）是**系统安全的"垂直空间法则核心"**，位于五层架构基础设施层。其核心原则：

> 气象服务决定了船"好不好开"，**海图服务决定了船"会不会死"**。

海图数据的处理逻辑是 CCS 船规 Nn 级认证的绝对红线，任何数据质量缺口直接影响系统认证。

### 2.2　两类采购需求

### 4.3　数据坐标基准要求

- **水平基准**：WGS84（EPSG:4326），不接受其他椭球体
- **垂直基准（水深）**：最低天文潮（LAT, Lowest Astronomical Tide）
- **垂直基准（高度）**：平均高水位（MHWS）或约定基准，须在元数据中明确标注
- **坐标精度**：水平位置精度与 CATZOC 等级对应，A1 级须达 ±5m

> **SINAN 工程注意**：海图服务引擎 A 执行 UTM 局部笛卡尔投影（20 NM 边缘距离形变 <0.1%），源数据须为 WGS84，不接受预投影格网数据。

## 第 5 章　数据精度与分辨率需求

### 5.1　水深数据精度需求

| 使用场景                        | 数据源              | 水深绝对误差要求           | CATZOC 最低要求 |
| ------------------------------- | ------------------- | -------------------------- | --------------- |
| 远洋航线规划（UKC G3 预扫描）   | S-57 / S-101 等深线 | ±2.0m（CATZOC B 可接受）   | B               |
| 近岸/航道 UKC 动态监测（10Hz） | S-102 水深网格      | ±1.0m（CATZOC A2）         | A2              |
| 浅水航道（马六甲、珠江口）      | S-102 水深网格      | ±0.5m+1%d（CATZOC A1）     | A1              |
| 港内靠泊水底剖面                | S-102 + 港口测深    | ±0.3m                      | A1              |

> **系统集成约束**：UKC 子系统在 S-102 不可用时自动降级至 `DEGRADED_TO_S57`（S-101 德劳内插值 + 最高 CATZOC 惩罚），该降级状态下系统强制降速并发出 `WARNING` 级别告警，不可作为正常运营模式。

### 5.2　S-102 水深网格分辨率需求

SINAN UKC 模块 M1 在内存中维护以本船为中心的 2.5D 滑动窗口张量，自适应分辨率如下：

| 航行场景     | SINAN 系统内部处理分辨率 | 原始 S-102 最低分辨率需求 |
| ------------ | ------------------------ | ------------------------- |
| 港口/狭水道  | 1m × 1m                  | **≤ 2m × 2m（必须）**     |
| 近海/沿海    | 10m × 10m                | ≤ 20m × 20m               |
| 远洋         | 50m × 50m                | ≤ 100m × 100m             |

> 45m ASD 拖轮船宽约 14m，港内模式下 1m 网格使船宽方向有约 14 像素分辨率，满足 COLAV 碰撞检测精度要求（工程设计中提出可选 2m 分辨率的局部加密模式，S-102 原始数据须支持此需求）。

### 5.3　S-104 水位数据精度需求

| 参数               | 需求                                         |
| ------------------ | -------------------------------------------- |
| 水位绝对精度       | ±0.1m（马六甲、珠江口强制要求）              |
| 水位预报时效       | 未来 ≥ 72 小时                               |
| 时间分辨率         | ≤ 1 小时（逐时潮高预报）                     |
| 空间分辨率         | ≤ 0.1° × 0.1°（约 10km 网格），港口须至本港验潮站 |

| MSI / NAVTEX 临时警告       | 实时（< 15 min） | NAVTEX 接收 + GMDSS 集成，或 MQTT 实时推送        |

### 6.2　航次驱动的热区裁剪

厂商的岸端系统须支持**航次驱动空间裁剪**（Voyage-Driven Tile Extraction）：

- 以 VRO 提供的 RTZ 格式航线为中轴，两侧各扩展 **≥ 20 NM**
- 执行 PostGIS `ST_Intersection` 裁剪后，转为 **GeoPackage 或 WKB 二进制流**
- 压缩方式：Zstandard（LZ4 也可接受）
- 完整性校验：**SHA-256 签名 + ECDSA**，生成 `Chart_Update_ID` 标签
- 下发协议：MQTT QoS 2（SINAN 船端零信任入库门控要求 TP 防重放 + TPM 验签）

### 6.3　断网离线保障

| 离线保障项目         | 要求                                                                                                                 |
| -------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 本地冷备库           | 船端 SSD 须存储相关航区全量冷备（解密后 PostGIS 形式），无网可独立使用                                              |
| 冷备切换时间         | 断网时冷备提取+投影响应 **< 500ms**（对应 CH-DoD-06 验收标准）                                                      |
| 降级操作模式         | 离网后强制假设最低天文潮（潮高=0），CATZOC 惩罚与安全裕量翻倍，禁航区膨胀                                           |
| 过期海图处置         | S-63 证书过期（> 所订阅周期）：船端 SINAN 自动切换 H1（仅告警显示），**禁止 H3 自主起航**；须触发 `ALARM` 级告警   |
| 更新超期警告阈值     | 岸端更新中断 **> 7 天**：船端广播 `CHART_UPDATE_STALE`，增大全局安全裕量                                            |

### 9.3　与 SINAN 系统集成接口要求（关键）

SINAN 是运行于 NVIDIA AGX Orin 的 ROS 2 系统，ECDIS 须通过以下接口与 SINAN 协同：

| 接口类型             | 协议/格式                              | 方向                         | 内容                                              |
| -------------------- | -------------------------------------- | ---------------------------- | ------------------------------------------------- |
| 航线导入/导出        | RTZ（IEC 61174）文件或 TCP Socket      | ECDIS ↔ SINAN VRO            | VRO 规划的参考航线导出至 ECDIS 显示；船员修改后 RTZ 导回 VRO |
| 船舶位置叠加         | NMEA 0183 GGA/VTG 或 ROS 2 NMEA 桥接  | SINAN → ECDIS                | 本船位置、航速、航向实时显示                      |
| 动态 No-Go 区叠加    | GeoJSON over TCP 或私有 API            | SINAN 海图服务 → ECDIS       | SINAN 动态渲染的 UKC 禁航区（Squat/Heave 修正后）实时叠加 ECDIS |
| ALM 等级状态显示     | NMEA 0183 ALR 告警报文 或 REST API     | SINAN ALM → ECDIS            | H1/H2/H3 自主等级、AMS 告警级别驾驶台联动显示    |
| COLAV 态势叠加       | AIS 格式或私有 JSONL over TCP          | SINAN COLAV → ECDIS          | 目标列表、DCPA/TCPA 威胁评估结果叠加显示          |
| ENC 数据回流（可选） | S-57 WKB 查询接口 或 OGC WFS           | ECDIS ENC 引擎 → SINAN       | SINAN 离港前允许从 ECDIS 本地解密库同步 ENC 数据  |

> **集成优先级**：RTZ 航线交换 和 动态 No-Go 区叠加 为 **P0 强制集成项**；其余接口为 P1 推荐集成项。

### 9.4　并排/备份配置要求

- 满足 SOLAS Reg. V/19.2.1.4 "同时运行两台 ECDIS"要求，可选双机方案
- 两台 ECDIS 须支持通过 LAN 进行航线和 ENC 数据同步（Copycat/Mirror 模式）
- 单台 ECDIS 软件故障不得导致 SINAN 主系统报警或控制中断（接口松耦合）
