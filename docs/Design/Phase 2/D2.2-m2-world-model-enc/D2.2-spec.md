## 2. 候选方案

### 方案 A：串行全功能实施（弃用）

按依赖顺序逐项实施：先 UKF 协方差 → 再置信度模型 → 再 ENC 集成 → 再字段补全。

| 优点 | 缺点 |
|---|---|
| 逻辑连贯，每步验证前一阶段 | 5.5 pw 严重不足——任何单项延期导致后续全部阻塞 |
| 适合单人开发 | ENC 集成与协方差链零依赖，串行浪费并行度 |

🟡 弃用——并行度为零，不符合 5.5 pw 时间窗口。

### 方案 B：并行轨道分解 🟢 选定

将 DoD 拆分为 5 个独立轨道，零依赖或单向依赖，可同时推进。

```
轨道 A (UKF 协方差链 + 置信度)  ←── 核心算法，1.5 pw
轨道 B (ENC 静态世界集成)      ←── 独立，1.2 pw
轨道 C (字段补全)              ←── 独立，0.8 pw
轨道 D (验证固化)              ←── 独立，0.5 pw
轨道 E (Python 测试)           ←── 独立，0.5 pw
────────────────────────────────────────
汇总集成 + 端到端验证           ←── 1.0 pw
────────────────────────────────────────
合计                           ←── 5.5 pw
```

| 轨道 | 人周 | 依赖 | 产出物 |
|---|---|---|---|
| A | 1.5 | 无（独立）| UKF CpaTcpaCalculator + 策略接口 + 协方差消息字段 + 置信度模型 |
| B | 1.2 | 无（独立）| EncLoader 端到端 + ZoneConstraint 填充 + 混合触发调度 |
| C | 0.8 | 无（独立）| intent_confidence 字段 + BRG/RNG + env sanity checks |
| D | 0.5 | 无（独立）| MUST-1 4 边界测试 + MUST-6 Manifest 端到端验证 |
| E | 0.5 | 无（独立）| Python s57_parser/s102_processor/ukc_calculator/geometry_serializer 测试 |
| 集成 | 1.0 | A+B+C+D+E 完成 | 端到端 World_StateMsg 验证 + DEMO-2 5 场景 ENC 高亮 |

**置信度**：🟢 — 5 轨道零依赖，可同时开工。即使任一轨道延误，不阻塞其他。1.0 pw 集成缓冲吸收意外。

### 方案 C：MVP 优先（弃用）

仅实施 DEMO-2 关键路径：意图字段 + BRG/RNG + 环境 sanity。UKF 和 ENC 端到端推迟到 Phase 3。

🟡 弃用——留下 ~3 pw 技术债，与 DEMO-2 "决策能力可视化"定位不匹配。

### 决策理由

方案 B 被选定因为：① 5 轨道**零依赖**，可 5 个 subagent 并行开发；② UKF 与 ENC 是 M2 决策级实装的核心差异化能力，推迟到 Phase 3 会弱化 DEMO-2 的价值主张；③ 5.5 pw 正好覆盖 5 轨道 + 1 pw 集成缓冲，预算对齐。

## 3. 选定方案详细设计

### 3.1 轨道 A：UKF CPA/TCPA 协方差链 + 置信度模型（1.5 pw）

#### 3.1.1 UKF sigma points 传播

**设计决策**：在现有 `CpaTcpaCalculator` 上叠加 UKF 路径，不重写已有线性方法。

**策略模式接口**（`include/m2_world_model/cpa_tcpa_calculator.hpp` 扩展）：

```cpp
enum class CpaCovarianceMethod {
    LINEAR,        // 现有：解析雅可比 + 线性传播（降级兜底）
    UKF_SIGMA,     // 新增：2n+1 sigma points
    CE_ADAPTIVE    // 预留接口：Phase 3 交叉熵自适应采样
};

struct CpaTcpaConfig {
    CpaCovarianceMethod covariance_method = CpaCovarianceMethod::UKF_SIGMA;
    // ... existing fields
};

// 新增接口
CpaResult compute_with_ukf(
    const OwnShipSnapshot& own,
    const TargetSnapshot& target,
    OddZone odd_zone
);
```

**UKF 实现要点**（`src/cpa_tcpa_calculator.cpp` 新增）：

- **状态向量** `x = [Δx, Δy, Δvx, Δvy]^T`（相对位置 + 相对速度，4 维）
- **协方差** `P = blkdiag(Σ_rel_pos, Σ_rel_vel)`，其中 `Σ_rel_vel` 含海流不确定度
- **Sigma 点**：2n+1 = 9 个点（`α=1e-3`, `β=2`, `κ=0`），计算时间 O(9 × CPA 函数调用) ≈ 0.1ms
- **非线性观测**：`h(x) = [CPA(x), TCPA(x)]^T`（CPA 二次型公式作为观测函数）
- **输出**：`CpaUncertainty { cpa_sigma_m, tcpa_sigma_s }`，正定性检查后写入消息

**与已有代码的关系**：UKF 作为 `compute()` 内的分支路径，共享外推对齐和 ODD 域安全系数缩放逻辑。现有 12 个 CpaTcpaCalculator 测试保留——UKF 路径新增 4 个专门测试。

**低速保护**（继承 v1.0 详设 §5.1.2，L318-320）：`||rel_vel|| < 0.1 m/s` → 跳过 UKF，CPA=||rel_pos||，TCPA=∞，协方差直接取目标位置协方差。

**关键参数**（`config/m2_params.yaml` 新增）：

```yaml
cpa_covariance:
  method: "ukf_sigma"           # linear | ukf_sigma | ce_adaptive
  ukf_alpha: 1.0e-3
  ukf_beta: 2.0
  ukf_kappa: 0.0
  min_rel_speed_ms: 0.1         # below this, skip UKF
  covariance_positive_definite_check: true
  covariance_default_pos_sigma_m: 50.0   # fallback if check fails
  covariance_default_vel_sigma_ms: 1.0
```

#### 3.1.2 协方差字段传播至消息

**TrackedTarget.msg 扩展**：

```
# 新增字段（追加到现有字段之后，保持 backward compatible）
float64 cpa_covariance_m2       # CPA 方差 (m²)，UKF 传播结果
float64 tcpa_covariance_s2      # TCPA 方差 (s²)，UKF 传播结果
```

- D2.2 spec 不使用 3×3 矩阵（`float64[9]`）——仅传播标量方差，因为 CPA/TCPA 是标量，其协方差矩阵只有对角元素有意义
- 正定性检查：`cpa_covariance_m2 > 0 && tcpa_covariance_s2 > 0`，否则设为保守默认值并记录 ASDR
- 协方差膨胀检测：`cpa_covariance_m2 > 2500.0`（σ > 50m）或 `tcpa_covariance_s2 > 100.0`（σ > 10s）→ 置信度下调

#### 3.1.3 置信度模型升级

**当前问题**：`WorldState.confidence = min(DV_conf, EV_conf, SV_conf)`——纯取最小值，不反映 CPA 质量。

**升级为**：

```
per_target_confidence = base_confidence * cpa_quality_factor * track_age_factor

其中:
  base_confidence = min(colreg_classification_confidence, sensor_confidence)
  cpa_quality_factor = 1.0 / (1.0 + cpa_cv)     # CV = sigma/mean ∈ [0, ∞)
    - cpa_sigma / cpa_mean < 0.1 → factor > 0.91  (🟢 high quality)
    - cpa_sigma / cpa_mean > 1.0 → factor < 0.50  (🔴 low quality)
  track_age_factor = 1.0 - exp(-track_age_s / 60.0)
    - track_age = 0s  → factor = 0.0  (新目标低置信)
    - track_age > 120s → factor > 0.86 (稳定跟踪高置信)
```

**WorldState 整体置信度**（继承 v1.0 详设联合保守原则，L96）：

```
WorldState.confidence = min(
    min(per_target_confidences),
    DV_health.confidence,
    EV_health.confidence,
    SV_health.confidence
)
```

### 3.2 轨道 B：ENC 静态世界端到端集成（1.2 pw）

#### 3.2.1 数据流

```
S-57 .000 文件 ──→ s57_parser.py ──→ EncPolygon[] JSON
                                            │
S-102 .h5 文件  ──→ s102_processor.py ──→ BathymetryGrid JSON
                                            │
                                    geometry_serializer.py
                                            │
                                            ▼
                              enc_metadata.json (预编译，启动时加载)
                                            │
                                            ▼
                              C++ EncLoader::load_metadata()
                                            │
                    ┌───────────────────────┼───────────────────────┐
                    ▼                       ▼                       ▼
            query_zone()             in_tss()              in_narrow_channel()
            (点-in-polygon)          (lane 边界)           (channel 边界)
                    │                       │                       │
                    └───────────────────────┼───────────────────────┘
                                            ▼
                              WorldStateAggregator::compose_world_state()
                                            │
                                            ▼
                              ZoneConstraint.msg (tss_lanes + exclusion_zones 填充)
```

**关键变化**：当前 `EncLoader` 仅返回 zone_type 枚举。D2.2 后返回完整多边形数据，由 `WorldStateAggregator` 通过 Boost.Geometry `within()` 做实时点-in-polygon 查询。

#### 3.2.2 混合更新策略

| 触发类型 | 机制 | 频率/条件 | 刷新范围 |
|---|---|---|---|
| **周期心跳** | 15s 定时器 | 每 15s | Dynamic horizon 内 full refresh |
| **路径段触发** | 订阅 L2 新航迹 | L2 新 WP list 到达时 | 路径 bounding box 内增量刷新 |
| **ODD 切换触发** | 订阅 M1 ODD_StateMsg | ODD zone 变化时 | 全量刷新（安全等深线随 ODD 变化）|

**实现**：`WorldModelNode` 新增一个 15s 定时器 + 一个 L2 path subscriber。`EncLoader` 新增 `refresh_horizon()` 和 `refresh_path_bbox()` 方法。

**Dynamic horizon**（继承 v1.0 详设 SV 缓存策略，L168-175）：以自船为中心，半径 `max(5 nm, 3 × CPA_safe(ODD))` 的动态窗口。窗口外数据保持粗粒度（仅 zone_type），窗口内做全精度查询。

#### 3.2.3 ZoneConstraint 消息填充

**当前**（`world_state_aggregator.cpp` L300 注释）：
```cpp
// tss_lanes 和 exclusion_zones 在 v1.0 中留空
```

**D2.2 后**：
```cpp
auto zone = ZoneConstraint{};
zone.zone_type = enc_loader.query_zone(own_pos);
zone.in_tss = enc_loader.in_tss(own_pos);
zone.in_narrow_channel = enc_loader.in_narrow_channel(own_pos);

// 新增：填充多边形数据
zone.tss_lanes = enc_loader.get_tss_lanes(own_pos);       // Polygon[]
zone.exclusion_zones = enc_loader.get_exclusion_zones(    // Polygon[]
    own_pos, dynamic_horizon_radius_m

zone.min_water_depth_m = enc_loader.get_min_depth(own_pos);
```

**exclusion_zones 格式**：GeoJSON Polygon（架构附录 F.9，L1997）

#### 3.2.4 UKC 计算集成

`ukc_calculator.py` 在 Python 预编译阶段运行，将 UKC 结果嵌入 `enc_metadata.json`。运行时 `EncLoader` 读取预编译 UKC 值（Barrass/Römisch 方阵 + CATZOC 信心系数）。

**不去做**：运行时调用 Python UKC 计算器（语言边界开销 + SOTIF 复杂性）。预编译 UKC 数据随 ENC 元数据一同加载，静态世界刷新时更新。

### 3.3 轨道 C：字段补全（0.8 pw）

#### 3.3.1 intent_confidence 字段

**设计决策**：遵循 B P1-B-02 评审决议——M2 仅输出标量置信度，M5 BC-MPC 自行穷举离散意图。

**TrackedTarget.msg 扩展**：

```
# 追加到现有字段之后
float32 intent_confidence  # 对目标意图认知的可信度 [0, 1]
```

**填充逻辑**（`WorldStateAggregator` 内新增 `compute_intent_confidence()` 方法）：

| 目标来源 | intent_confidence | 说明 |
|---|---|---|
| AIS Class A + 有效 ETA/目的地 | 0.70 | AIS Type 5 字段完整时 |
| AIS Class B（无目的地信息）| 0.50 | 仅能推断存在性 |
| 纯 Radar 跟踪（无 AIS）| 0.30 | 传感器仅提供运动学 |
| 新目标（track_age < 30s）| 0.10 | 尚无行为模式 |
| 行为模式与 COLREG 预期一致 | +0.10（上限 0.95）| 如小船在航道内直航 |
| 行为模式异常（如商船在锚地高速机动）| -0.20（下限 0.05）| 意图不确定性升高 |

**与 M5 的契约**：M5 BC-MPC 读到 `intent_confidence` 后，按 Eriksen 2020 原始算法自行穷举 `{straight, +20°, -20°, accelerate, decelerate}`，不做 `intent_distribution` dict 解析。

#### 3.3.2 BRG/RNG per-target 输出

**TrackedTarget.msg 扩展**：

```
float64 brg_deg    # 真方位（bearing from own ship to target, 0°=真北）
float64 rng_m      # 距离（range from own ship to target, meters）
```

**计算**（在 `WorldStateAggregator` 的 `compose_world_state()` 循环中新增）：
```cpp
// 已有 rel_pos = target_pos - own_pos (ENU 坐标)
target_msg.brg_deg = atan2(rel_pos.x, rel_pos.y) * 180.0 / M_PI;
if (target_msg.brg_deg < 0) target_msg.brg_deg += 360.0;  // 规范到 [0, 360)
target_msg.rng_m = rel_pos.norm();
```

**前端对接**：D1.3.2.3 Web HMI `ArpaTargetTable.tsx` 当前硬编码 `"—"`，D2.2 完成后改为读取 `brg_deg` / `rng_m` 字段（无 IDL 变更，仅消息字段使用）。

#### 3.3.3 环境字段 sanity checks

**实现位置**：`WorldStateAggregator` 内新增 `EnvSanityChecker` 内嵌类。

| 校验项 | 规则 | 违反行为 |
|---|---|---|
| **visibility** | ∈ [0.01, 50.0] nm | 超出范围 → 标记 SV DEGRADED，使用前值 |
| **Hs（有义波高）** | ∈ [0.0, 20.0] m | 超出范围 → 标记 SV DEGRADED + ASDR 记录 |
| **current_speed** | ∈ [0.0, 10.0] kn | 超出范围 → 海流分量设 0 + confidence *= 0.8 |
| **current 与 zone 一致性** | 港内 current > 5 kn 判定为不合理 | 标记异常 + ASDR 记录（但不阻止使用——可能是急流航道）|
| **staleness** | environment_msg 年龄 > 60s | 标记 SV DEGRADED（继承 v1.0 详设 L669，宽松为 60s）|
| **zone_type 跳变** | OPEN → PORT 需经 NARROW_CHANNEL 过渡（单次跳变允许，二次跳变拒绝）| 使用缓存 zone_type + ASDR 记录 |
| **跨源温度一致性** | 水温（如有）与 air_temp 偏差 > 30°C | 标记 SOTIF 异常事件（不阻塞）|

**降级行为**：SV DEGRADED → `zone_constraint` 沿用上次有效值 + `SV_health.confidence = 0.5`；SV CRITICAL（>120s 未更新）→ `zone_constraint` 仅保留 zone_type，tss_lanes/exclusion_zones 清空。

## 6. 风险与缓解

| # | 风险 | 等级 | 缓解 |
|---|---|---|---|
| R2.2.A | UKF 实现比预期复杂，算力超 Jetson 预算（50 Hz 下 N=15 目标）| 🟡 | 9 个 sigma 点 × 15 目标 = 135 次 CPA 评估/周期，@50 Hz ≈ 6750 次/s。CPA 函数 O(1)，UKF 总开销 < 1ms。若超标，降级为 UKF @ 4 Hz（聚合频率而非目标更新频率）|
| R2.2.B | S-57 真实 .000 文件复杂度超出 parser 能力（符号化/多尺度/SCAMIN）| 🟡 | 仅处理 DEPARE/OBSTRN/TSSLPT/LNDARE 4 层，不做完整 S-57 解析。CI 使用预编译 mock 数据。 |
| R2.2.C | 协方差正定性检查失败率高（传感器噪声模型不匹配）| 🟡 | 保守默认值兜底（σ_pos=50m, σ_vel=1 m/s），记录 ASDR 频率便于 HAZID 追溯 |
| R2.2.D | Manifest 读取路径跨语言边界（C++ ↔ Python 通信开销）| 🟢 | D1.1 已打通 ROS2 topic，Manifest 通过 `/l3/param/manifest` 发布，C++ 端已有订阅代码路径 |
| R2.2.E | BRG/RNG 坐标系混淆（磁北 vs 真北）| 🟢 | 统一使用真北（WGS84 ENU），MUST-1 测试覆盖 360° / 0° 边界 |
