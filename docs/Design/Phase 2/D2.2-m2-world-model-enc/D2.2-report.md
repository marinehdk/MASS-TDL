## 3. 接口契约摘要

### 上游订阅（不变，继承自 spec §4.1）

| Topic | 来源 | 频率 | 关键字段 |
|---|---|---|---|
| `/perception/targets` | Multimodal Fusion | 2 Hz | TrackedTargetArray（WGS84，sog/cog 对地）|
| `/nav/filtered_state` | Nav Filter | 50 Hz | FilteredOwnShipState（u/v 对水 + 海流估计）|
| `/perception/environment` | Multimodal Fusion | 0.2 Hz | EnvironmentState（visibility/Hs/zone_type/in_tss）|
| `/l3/m1/odd_state` | M1 ODD Manager | 1 Hz + event | ODD_StateMsg（current_zone, auto_level）|

### 下游发布（扩展，per spec §4.2）

| Topic | 目标 | 频率 | 变更说明 |
|---|---|---|---|
| `/l3/m2/world_state` | M3 / M4 / M5 / M6 | 4 Hz | TrackedTarget 追加 5 字段；ZoneConstraint.tss_lanes/exclusion_zones 从空 → 填充 |
| `/l3/m2/sat_data` | M8 HMI Bridge | 10 Hz | 新增 CPA/TCPA 不确定性统计（max/min cpa_cv）|
| `/l3/m2/asdr_record` | ASDR | event + 2 Hz | 新增 ENC 刷新 / 协方差膨胀 / env sanity 违反事件 |

### IDL 变更（per spec §4.3）

| 文件 | 变更 | Backward Compatible |
|---|---|---|
| `l3_msgs/msg/TrackedTarget.msg` | 追加 5 字段（cpa_covariance_m2, tcpa_covariance_s2, intent_confidence, brg_deg, rng_m）| ✅ 追加，旧消费者忽略新字段 |
| `l3_msgs/msg/ZoneConstraint.msg` | tss_lanes + exclusion_zones 已有字段定义，变更为填充 | ✅ 字段已存在 |
| `l3_msgs/msg/WorldState.msg` | 无变更 | ✅ |
| `m2_world_model/config/m2_params.yaml` | 新增 cpa_covariance + enc_update 段 | N/A |

### 置信度字段

`confidence ∈ [0, 1]` 全字段，由 `cpa_quality_factor × track_age_factor × base_confidence` 计算。协方差膨胀（cpa_sigma > 50m 或 tcpa_sigma > 10s）时自动下调置信度。

## 4. 降级路径摘要

| 降级状态 | 触发条件 | M2 行为 |
|---|---|---|
| **SV DEGRADED** | environment_msg 年龄 > 60s；visibility/Hs/current 超出范围 | zone_constraint 沿用上次有效值；SV_health.confidence = 0.5 |
| **SV CRITICAL** | SV 未更新 > 120s | zone_constraint 保留 zone_type；tss_lanes/exclusion_zones 清空 |
| **UKF 降级** | 协方差正定性检查失败 | 回退线性传播；cpa_covariance 设保守默认值（σ_pos=50m）；记录 ASDR |
| **低速保护** | ‖rel_vel‖ < 0.1 m/s | 跳过 UKF；CPA=‖rel_pos‖；TCPA=∞；协方差取目标位置协方差 |
| **ENC 数据丢失** | EncLoader 加载失败 | ZoneConstraint 仅保留 zone_type（来自 EnvironmentState）；SV 标记 DEGRADED |
| **Manifest 不可用** | MUST-6 Manifest 加载失败 | sog 校验使用默认值 50 kn |

## 5. CCS 映射

M2 World Model 职责映射至 DNV-CG-0264（CCS 智能船舶规范）子功能：

| M2 子能力 | DNV-CG-0264 子功能 | 说明 |
|---|---|---|
| 目标状态融合（DV/EV/SV 三视图）| **S1** 传感器数据处理 | 多源感知数据汇聚为唯一权威世界视图 |
| CPA/TCPA 协方差计算 | **S2** 态势评估 | 碰撞风险量化，含不确定度 |
| COLREG 几何预分类（OVERTAKING/CROSSING/HEAD_ON）| **S2** 态势评估 | 为 M6 COLREGs Reasoner 提供分类前件 |
| ENC 静态世界集成（ZoneConstraint 填充）| **S1** 传感器数据处理 | 航海图静态约束嵌入世界视图 |
| 环境 sanity checks | **S1** 传感器数据处理 | 传感器输入质量过滤 |
