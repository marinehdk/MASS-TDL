### 3.4 OU 目标船接口

`TargetVessel(mode=TargetMode.NCDM, ou_theta=0.05, ou_sigma=0.5)` 参数含义：

| 参数 | 含义 | 默认值 | 典型范围 |
|---|---|---|---|
| `ou_theta` | 回归强度（1/min 量级）| 0.05 | [0.01, 0.2] |
| `ou_sigma` | 扰动幅度（°/√s）| 0.5 | [0.1, 2.0] |

OU 过程：`dH = -θ (H - H₀) dt + σ √dt · N(0,1)`（H₀ 为初始航向，离散化 Euler-Maruyama）。

scenario YAML 新增字段：
```yaml
target_vessels:
  - mmsi: 123456789
    motion_model: ncdm
    ou_theta: 0.05
    ou_sigma: 0.5
```

## 4. 6D 评分引擎完整规约

> D1.7 `03-coverage-metrics.md §5` 是算法权威；本节为 D2.4 实装时的变更清单。

### 4.1 需要修改 hagen_scorer.py 的三处

**[Fix-1] key 不一致**：
```python
# 当前（错误）
score_map = {"ok": 1.0, "partial": 0.5, "violated": 0.0}
# 修改后（与 D1.7 §5.2 对齐）
score_map = {"full": 1.0, "partial": 0.5, "violated": 0.0}
```

**[Fix-2] action_magnitude_penalty 公式**：
当前 `deviation = |rudder_deg - 60°| - 30°`（ideal center 60°）与 D1.7 §5.4 的 ideal range [30°, 90°] 定义一致（中点 60°），但需验证边界逻辑，确认：
- `rudder_deg ∈ [30°, 90°]` → penalty = 0
- `rudder_deg < 30°` → `((30° - |rudder|) / 30°)²`
- `rudder_deg > 90°` → `((|rudder| - 90°) / 30°)²`

若现有实现边界正确则不改，仅加注释确认。

**[New-1] compute_verdict()**：
```python
def compute_verdict(
    self, min_cpa_nm: float, rule_states: Dict[str, str],
    grounding: bool = False
) -> bool:
    return (
        min_cpa_nm >= self.cpa_target_nm
        and all(v in ("full", "partial") for v in rule_states.values())
        and not grounding
    )
```

**[New-2] get_quality_score()** = 原 `get_final_verdict()` 改名，逻辑不变。

**[New-3] score_frame() 返回 ScoringRow 扩展**：
```python
@dataclass
class ScoringRow:
    ...                          # 原 10 字段不变
    pass_fail: bool = False      # 新增
    applicable_rule: str = ""    # 新增（e.g. "Rule14"）
```

```cpp
// 伪代码 — 精确实现见 plan
auto chain = build_colregs_chain(primary_target_id_);

// Layer 1: ODD
chain[0] = make_chain_layer(1, "ODD", odd_domain_str(current_odd_), {});

// Layer 2: 规则集
chain[1] = make_chain_layer(2, "规则集",
    format_active_rules(applicable_rules_), {});

// Layer 3: 会遇分类
chain[2] = make_chain_layer(3, "会遇分类",
    encounter_type_str(enc_type),
    {{"bearing_deg", geo.bearing_deg}, {"cpa_nm", geo.cpa_m / 1852.0}});

// Layer 4: 责任分配
chain[3] = make_chain_layer(4, "责任分配",
    role_str(assigned_role_),
    {{"aspect_deg", geo.aspect_deg}});

// Layer 5: 时机
chain[4] = make_chain_layer(5, "时机",
    timing_stage_str(timing_phase_.stage),
    {{"tcpa_s", geo.tcpa_s}, {"t_standon_s", params_.t_standOn_s}});

msg.colregs_chain_target_id = primary_target_id_;
```

`primary_target_id_` = CPA 最小的活跃目标 MMSI（当多目标并发时，展示危险度最高的那条 chain）。

### 5.3 何时 chain 为空

- 无活跃目标（`constraints.empty()`）→ `colregs_chain` 为空 array，前端 `ColregsRationaleTree` 渲染"无会遇"状态
- M6 处于 DEGRADED（confidence < 0.5）→ chain[5] 仍填充，但每层 confidence 置 0.3
- M6 处于 FAILED → chain 为空，rationale = "M6 FAILED"

## 6. ncdm_vessel OU 模式

### 6.1 实装位置

`src/sim_workbench/sil_nodes/target_vessel/target_vessel/node.py`

### 6.2 OU 过程 Euler-Maruyama 离散化

```python
class TargetVessel:
    def __init__(self, ..., mode=TargetMode.REPLAY,
                 ou_theta: float = 0.05,
                 ou_sigma: float = 0.5):
        ...
        self._ou_theta = ou_theta
        self._ou_sigma = ou_sigma
        self._heading_ref = self.heading   # OU 回归基准（初始航向）

    def step(self, dt: float = 0.1) -> dict:
        if self.mode == TargetMode.NCDM:
            import random
            dH = (
                -self._ou_theta * (self.heading - self._heading_ref) * dt
                + self._ou_sigma * math.sqrt(dt) * random.gauss(0, 1)
            )
            self.heading += dH
        # 原线性运动逻辑继续
        ...
```

OU 参数通过 scenario YAML `motion_model.ou_theta / ou_sigma` 注入；若缺省则使用构造器默认值。

### 7.2 提取脚本

`tools/sil/extract_ais_encounters.py`

```
输入：AIS CSV (mmsi, timestamp, lat, lon, cog, sog)
算法：
  1. 对每对船舶组合，滑窗计算 DCPA / TCPA
  2. 过滤：DCPA ≤ 2.0 NM AND TCPA ∈ [0, 30 min]
  3. 按 encounter bearing 自动 COLREGs 分类 (Rule 13/14/15)
  4. 输出：≥5 个 maritime-schema YAML，覆盖 Rule 13/14/15 各 ≥1

输出：scenarios/ais_derived/ais_{rule}_{n:02d}.yaml
```

YAML 格式遵循 `docs/Design/SIL/02-scenario-schema.md`（maritime-schema）。
