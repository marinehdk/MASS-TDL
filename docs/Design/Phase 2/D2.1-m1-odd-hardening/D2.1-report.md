## 4. 降级路径摘要

取自 spec §5。

| 触发条件 | M1 行为 |
|---|---|
| **DEGRADED**（传感器降质，Conformance_Score ∈ [0.5, 0.8]）| health=DEGRADED；score × stale_degradation_factor；不触发 MRC |
| **CRITICAL**（关键传感器失效 或 M7 VETO 到达）| 直接进入 MrCPrep；health=CRITICAL |
| **OUT_of_ODD**（Conformance_Score < 0.5）| TDL>TMR → 先发 tor_request→MrCPrep；TDL≤TMR → 直接 MrCActive |
| **Capability Manifest 缺失** | M1 启动失败，不进 IN 状态 |
| **M7 VETO 到达** | 立即 MrCPrep，不经过自身 FSM 判断（Checker 权威 > Doer）|
| **M7 心跳丢失**（> 500ms）| M1 自动 DEGRADED |
| **M2 输入 stale**（> 2s）| Conformance_Score × stale_degradation_factor |
