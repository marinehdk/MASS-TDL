## 4. 降级路径摘要

| 状态 | 触发条件 | M3 行为 |
|---|---|---|
| ACTIVE + current HIGH | XTE > 0.5 nm 或海流 > 2.0 kn | mission 继续；ASDR HIGH；`MissionGoalMsg.confidence × 0.85`（不低于 0.4）|
| ACTIVE + L1 WARNING | L1 断联 60–120 s | mission 继续；`confidence ≤ 0.6`；ASDR WARNING |
| ACTIVE + L1 TIMEOUT | L1 断联 > 120 s | mission 继续直至 ToR；`confidence ≤ 0.4`；`ToR_RequestMsg(MANUAL_REQUEST, 60s)` |
| L4 不可用（XTE stub）| L4 消息 > 2 s stale | `xte_nm=-1`；severity 由海流单源决定；mission 不中断 |
| OUT-of-ODD | M1 超时 > 2 s | 假设 ODD-C；`ToR(SAFETY_ALERT, 30s)` |
