## Lessons Learned

- Python 3.14 `@dataclass` 装饰器要求模块在 `sys.modules` 中注册，`importlib.util` 动态加载需显式 `sys.modules[name] = mod`
- `_run_cell_worker` 必须是模块级函数（非嵌套）才能被 `multiprocessing.Pool` pickle
- `scipy.stats.qmc.Sobol.random_base2(m=...)` 的 `m` 参数须为正整数，`max(1, int(log2(n)))` 确保安全
- NomotoVessel 1-DOF 模型在 600s 仿真中 give_way 角色可稳定避碰至 CPA > 0.27 NM
