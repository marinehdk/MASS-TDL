## 6. pandoc + LaTeX PDF 生成方案

**作业位置**：新建 `scripts/gen-pdf.sh`（Wave 2 同步产出）

```bash
#!/usr/bin/env bash
# scripts/gen-pdf.sh — 架构报告 v1.1.3 PDF 生成脚本
# 依赖：pandoc ≥ 3.0 + texlive-xetex + fonts-noto-cjk
# 用法：bash scripts/gen-pdf.sh [output-dir]

set -euo pipefail

SRC="docs/Design/Architecture Design/MASS_ADAS_L3_TDL_架构设计报告.md"
OUT="${1:-dist}/MASS_ADAS_L3_TDL_架构设计报告_v1.1.3.pdf"
mkdir -p "$(dirname "$OUT")"

pandoc "$SRC" \
  -o "$OUT" \
  --pdf-engine=xelatex \
  --toc \
  --toc-depth=3 \
  -V documentclass=article \
  -V geometry:margin=2.5cm \
  -V mainfont="Noto Serif CJK SC" \
  -V CJKmainfont="Noto Serif CJK SC" \
  -V fontsize=11pt \
  -V colorlinks=true \
  -V linkcolor=blue \
  --highlight-style=tango

echo "PDF 生成完成：$OUT"
```

**CI 集成**（可选，Wave 2 评估）：GitHub Actions `on: push to main` → `bash scripts/gen-pdf.sh dist/` → 上传 artifact。

**字体安装（macOS）**：
```bash
brew install --cask font-noto-serif-cjk
brew install basictex
sudo tlmgr install xecjk ctex
```
