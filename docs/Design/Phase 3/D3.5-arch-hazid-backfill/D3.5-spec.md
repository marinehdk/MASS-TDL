## 3. 参数分类框架

### 3.1 IEC 61508-3 三分类定义

| 类别 | 定义 | 改动影响 | 默认操作 |
|---|---|---|---|
| **Configuration** | 编译时耦合；改动生成新二进制或改变执行图结构 | 行为分支拓扑改变 | 全量回归 + D3.8 版本说明 |
| **Independent calibration** | 运行时输入；对其他参数无耦合，单独影响数值阈值 | 仅数值变化，控制流不变 | 热加载白名单（满足 AoU + 范围校验）|
| **Dependent calibration** | 运行时输入；安全行为依赖多参数联合值（joint AoU）| 联合值可能跨越行为分支边界 | CIA 后决定：通过则热加载，否则回归 |

以下参数已有充分文献依据，对行为分支结构无影响，7/31 前从 `[初始设计值]` 升格为 `[文献基线]`：

| 参数 | 当前值 | 文献依据 | AoU 范围 | 章节 |
|---|---|---|---|---|
| T_standOn (ODD-A) | 8 min | Wang 2021 + Imazu 1987 COLREGs 几何分析 | 6–12 min | §9.3 |
| T_act (ODD-A) | 6 min | 同上（T_standOn × 0.75 原则）| 4–9 min | §9.3 |
| T_standOn (ODD-B) | 4 min | Wang 2021 受限水域缩短系数 | 3–6 min | §9.3 |
| Rule 19 能见度触发阈值 | 1.0 nm | COLREG Rule 19(b) 字面值 | 固定（规范值）| §9.x |
| Rule 8 "大幅" 转向角下限 | 30° | COLREGs Rule 8 "large alteration" 文字 + MMG 灵敏度 | 20–45° | §9.2 |

### 3.3 需全量回归的参数（8/19 后处理）

以下参数改动会触发行为分支路径变化或联合 AoU 约束，不进热加载白名单，须等 HAZID RUN-001 结果后运行全量 Imazu 回归。

| 参数 | IEC 61508 类别 | 说明 | 影响范围 |
|---|---|---|---|
| IvP pieces 数量 | **Configuration** | 改变仲裁空间维度，影响 IvP solver 编译配置 | M4 行为仲裁全路径 |
| Conformance_Score 权重 (w_E, w_T, w_H) | **Dependent calibration** | 三者之和=1，联合影响 ODD 判定边界；任一权重独立修改可使另两者隐式越界 | M1 ODD 状态机所有路径 |
| ODD-A/B/C/D CPA/TCPA 阈值 | **Dependent calibration** | 多阈值联合决定子域分类，改变状态机路径 | M1、M6 全路径 |
| ToR 自适应矩阵（16 单元秒数）| **Dependent calibration** | 联合约束 TMR 窗口；单元独立调整可导致相邻状态路径冲突 | M1 ToR 触发链 + M8 HMI |

### 3.4 热加载白名单运行时约束（合规门槛）

进入白名单的参数，D2.1 M1 实装时须满足：

```
1. AoU 验证：启动时从 YAML 读取 → 范围校验 → 超范围拒绝并回退安全默认值
2. 无控制流改变：参数仅影响数值计算，不触发 if/switch 新分支
3. 变更日志：每次 YAML 覆盖触发 ASDR 事件记录（param_id + old_value + new_value + timestamp）
```

### 4.3 回归脚本接口（`regression_runner.sh`）

```bash
#!/usr/bin/env bash
# Usage: ./regression_runner.sh <override_yaml> [<scenario_filter>]
# override_yaml: hazid_calibrated.yaml (覆盖 fcb_dynamics.yaml 格式)
# scenario_filter: 受影响参数对应场景子集（默认跑全部 22 Imazu）

OVERRIDE_YAML=${1:-evidence/hazid_calibrated.yaml}
FILTER=${2:-"all"}
BASELINE_CSV=${3:-evidence/traceability_baseline.csv}
OUTPUT_DIR=evidence/regression_$(date +%Y%m%d_%H%M%S)

mkdir -p "$OUTPUT_DIR"

# 1. 生成覆盖参数集
cp "$OVERRIDE_YAML" /tmp/d3_5_override.yaml

# 2. 启动仿真器（YAML 覆盖）并跑场景
ros2 launch fcb_simulator simulator.launch.py \
  params_file:=/tmp/d3_5_override.yaml \
  scenario_filter:="$FILTER" \
  output_csv:="$OUTPUT_DIR/traceability_calibrated.csv"

# 3. 差异对比
python3 evidence/diff_traceability.py \
  --baseline "$BASELINE_CSV" \
  --calibrated "$OUTPUT_DIR/traceability_calibrated.csv" \
  --output "$OUTPUT_DIR/regression_report.md"

echo "Report: $OUTPUT_DIR/regression_report.md"
```

**场景过滤逻辑**（`diff_traceability.py` 内）：

- Configuration / Dependent 类参数变更 → 跑全 22 Imazu 场景
- Independent 类参数变更 → 只跑该参数影响的规则子集（如 T_standOn 只跑 Rule 15/16/17 相关场景）
