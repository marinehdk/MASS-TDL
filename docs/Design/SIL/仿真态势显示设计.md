# 🛡️ ADAS L3 TDL 仿真运行态势与交互显示详细设计 Spec

在当前的 **“仿真运行”（Simulation Monitor）** 页面设计中，系统面向 **本船（Own Ship）** 及其周边复杂的通航环境，设计了全新一代的 **“左态势、右诊断、底脉搏”** 结构化人机交互（HMI）框架。

本规范定义了仿真态势显示的信息分类、布局映射、气泡吸附交互以及系统调测模块的标准，作为实装开发的详细设计 Spec。

---

## 🏛️ 一、 交互显示核心架构与工效学原则

为了避免传统仿真界面“信息罗列无主次、数据东一块西一块”的问题，本设计基于 **操作员/船长（态势感知与高层决策）** 与 **算法研发工程师（中底层状态与诊断）** 两个维度，对信息流进行解耦与重新聚类。

```
+-----------------------------------------------------------------------------+
|                           [1. 顶栏：系统时空状态与大盘]                       |
+---------------------+---------------------------------+---------------------+
|                     |                                 |                     |
|  [2. 左侧栏]        |         [4. 海图中心视口]       |  [3. 右侧栏]        |
|  船长态势舱         |                                 |  工程师调测舱       |
|                     |        本船/目标/安全圈         |                     |
|  - 本船状态 TAB     |        CPA评估/等深线           |  - ASDR记录 TAB     |
|  - 威胁列表 TAB     |                                 |  - 实时评分 TAB     |
|  - 避碰决策 TAB     |   +------------+------------+   |  - 故障注入 TAB     |
|                     |   | 比例尺   | M1-M8 脉搏 | |  |                     |
|  (默认完全折叠)     |   +------------+------------+   |  (默认完全折叠)     |
|  [▶ 拉手展开]       |   [5. 底部本地气泡 popover]     |  [◀ 拉手展开]       |
+---------------------+---------------------------------+---------------------+
|                           [6. 底栏：时间轴与播放控制]                         |
+-----------------------------------------------------------------------------+
```

### 1. 双边侧栏对称折叠 (Dual Symmetrical Collapsed Sidebars)
- **设计初衷**：最大化保留海图（中心主视口）的安全瞭望和态势绘图视野。
- **展现机制**：
  - **左侧栏 (船长态势舱)** 与 **右侧栏 (工程师调测舱)** 在系统初始化时**默认处于 100% 折叠隐藏状态**。
  - 屏幕最左侧和最右侧边缘常驻高度 72px 的极简垂直拉手。点击左侧拉手（**▶**）向右滑动展开左侧栏；点击右侧拉手（**◀**）向左滑动展开右侧栏。展开后拉手箭头方向自动反转。

### 2. 信息聚类分级 (Logical Information Clustering)
- **左侧栏（操作导向）**：专为船长/ROC操作席设计，遵循 **“我的船在哪？ $\rightarrow$ 谁是威胁？ $\rightarrow$ 系统现在正在做什么？”** 的天然直觉。
- **右侧栏（诊断导向）**：专为算法测试与发布控制设计，展示审计日志、SOTIF 分值与仿真故障注入。
- **底部门户（气泡吸附）**：将底部的 M1-M8 脉搏状态条作为本地调试诊断的统一入口。

## 👈 二、 左侧栏设计：船长态势舱 (Captain Cockpit)

左侧栏宽度为 **320px**，背景采用暗色磨砂玻璃（`rgba(11, 15, 25, 0.95)`，模糊度 16px），包含 3 个并排标签页（Tabs）：

### Tab 1: 【本船状态】 (Own Ship Status)
实时呈现本船的绝对航仪参数与航次任务进度，确保时空一致性。
- **本船实步数据**：
  - **HDG (船首向)**：精确至 0.1°，动态代表物理艏向。
  - **COG (对地航向)**：精确至 0.1°，代表实际对地运动方向。
  - **SOG (对地航速)**：精确至 0.1 kn，青色高亮。
  - **ROT (转向率)**：精确至 0.1°/min，展示当前的偏航强度。
- **航次计划段跟踪**：
  - **当前主航线**：展示全局计划航线的名称。
  - **目标路点 (Active Waypoint)**：高亮展示当前正在跟踪的路点编号（如 `WP04`）及水域属性（如“开阔水域”）。
  - **路点剩余距离 / 预计抵港时间 (ETA)**：展示到达终点的海里数及精确至秒的 ETA。

### Tab 2: 【威胁列表】 (Threat List / ARPA)
通过感知传感器（雷达、AIS）融合输出周边的通航威胁，引导用户快速判明碰撞风险。
- **高风险威胁船 (Target 1 / Lead Threat)**：
  - 系统智能提取当前 CPA/TCPA 最具危害性的单目标作为首要威胁卡片，卡片左边框以 3px 警戒红（`#f87171`）高亮，带有 **`CRITICAL RISK`** 状态标签。
  - 核心展示：目标 MMSI、目标 COG/SOG、相对方位角 (BRG)、物理距离 (RNG)。
  - **红色双爆指标**：当 CPA 距离小于安全领域上限（如 0.5 nm）且 TCPA 倒计时小于 6 min 时，**CPA 和 TCPA 指标强制爆红显示**，提醒操作员规避。
- **周边其它监控目标表**：
  - 采用极简微型表格展示周边其他 3~5 个次要目标。
  - 包含列：`MMSI`、`RNG`、`CPA`、`安全等级` (如 `安全🟢` / `警惕🟡`)。

### Tab 3: 【避碰决策】 (Avoidance Decisions / FSM)
将算法计算的宏观结果翻译为符合《国际海上避碰规则》(COLREGs) 的人类语义，作为高层动作指令。
- **规则状态机 (FSM State)**：
  - 常驻当前 FSM 核心决策状态：`COLREG_AVOIDANCE` (自动避碰状态) / `TRANSIT` (自主航行) / `TOR` (请求接管) / `MRC` (最小风险操作)。
  - 标记当前决策的算法置信度 / 权重系数。
- **避碰规则对齐**：
  - 翻译避碰关系：如“根据《避碰规则》第 14 条 (对遇 Head-on)，本船承担让路义务 (Give-way)”。
- **船长决策行动指令 (Action Command)**：
  - 以高对比青色横幅常驻展示宏观动作建议，如 **“转向动作：本船向右转向 15° 以宽让目标船”**，让操作人员对自动驾驶的行为心中有数。

## 👉 三、 右侧栏设计：工程师调测舱 (Engineer Cockpit)

右侧栏宽度为 **340px**，同样采用磨砂玻璃效果，作为中底层调测与仿真审计的界面，包含 3 个标签页：

### Tab 1: 【ASDR 记录】 (Audit Ledger)
- **功能定位**：满足 ADAS L3 对自主决策的审计需求（Autonomous System Decision Recorder）。
- **展示形式**：以高密度的单色等宽字体滚动呈现最近发生的决策事件流水（最近 30 条）。
- **事件分类**：
  - `COLREG_TRIGGERED`：避碰关系被激活（标明适用规则与目标 ID）。
  - `ODD_VALIDATED`：M1 运行域通过周期性验证。
  - `WPT_PASS_COMPLETED`：路点通过通知。
  - `FAULT_INJECTED`：仿真注入故障记录（红色警告标识）。

### Tab 2: 【实时评分】 (Scoring Gauges)
- **功能定位**：在 SIL 运行中实时对算法的控制精度、合规程度和安全性进行多维度量化评估。
- **展示形式**：采用 3 组带分值的微型进度环：
  - **安全避障得分 (96分)**：评价本船与目标船的安全距离保持情况。
  - **规则依从得分 (82分)**：评价向右转向幅度、让路早让、宽让的执行合规性。
  - **轨迹跟踪得分 (98分)**：评价与全局航线的重合精度 (横向偏差控制)。
- **评语辅助**：为每一维分值提供简短的专家系统评语。

### Tab 3: 【故障测试注入】 (Fault Injection Panel)
- **功能定位**：SIL 环境下对控制链容错能力的实机干预工具。
- **注入项目**：
  - **感知雷达雪崩丢点**：注入物理目标在追踪雷达中突发全部丢失的异常。
  - **双轨不一致异常**：强行注入 Doer 与 Checker 轨迹不一致，触发 M7 安全 Veto。
  - **海图等深通信中断**：强行切断海图数据链，制造搁浅风险。
  - **紧急远程干预接管**：模拟远程 ROC 发送 Hardware Override 指令。
- **联动反应**：点击任意故障注入，右侧 ASDR 会**立即生成带时间戳的报警事件**，且顶栏时钟框闪烁红光警示。

## 🖥️ 四、 底部调试栏与气泡吸附交互 (Contextual Popover)

这是解决右侧栏功能项过多、视线跨屏跃迁严重的核心重构设计。

```
+-------------------------------------------------------------+
|  [气泡卡片：M6 COLREGs 避碰规则推理树]                       |
|  - ODD 验证: Rule 5 (100%)                                 |
|  - 会遇阶段: Head-on (95%)                                 |
|  - 责任划分: Give-way (100%)                                |
|  - 避碰动作: Compliant                                      |
+------------------------------v------------------------------+
                               | (气泡三角指向针)
+------------------------------+------------------------------+
| M1-ODD | M2-RT | M3-MIS | M4-ARB | M5-MPC | M6-COL | M7 | M8  |
+-------------------------------------------------------------+
```

### 1. 布局与几何对齐
- **位置**：整体水平居中悬浮于海图中心视口的底部（紧贴下方时间播放轴之上）。
- **水平对齐**：其左端与左下角的 **比例尺 (PPI Scale)** 高度水平齐平；其右端与右下角的 **底图切换器 (Layer Switcher)** 高度水平齐平，三者底边缘位于同一高度轴线。
- **卡片划分**：包含 8 个宽度完全相同的微型卡片，代表 **M1 至 M8 的决策规划规划接口**：
  - 卡片顶部：`M1-ODD`、`M2-RT` 等模块英文简称。
  - 卡片中部：放置一枚呼吸发光心跳灯（🟢 绿色正常 / 🟡 黄色警告 / 🔴 红色断线或降级）。
  - 卡片底部：标注该模块实时的计算时延 (Latency)（如 `4ms` / `1Hz`），提示数据新鲜度。

### 2. 吸附式局部诊断气泡 (Floating Popover)
- **交互逻辑**：
  - 用户**点击** 8 等宽卡片中的任意一个，会在**该卡片的正上方垂直弹出一个深色半透明磨砂气泡卡片**（Floating Popover）。
  - 气泡底部带有一个实心的三角指向针，精准对齐指向被点击激活的模块卡片。
  - 点击卡片外部、“×”关闭按钮，或再次点击当前激活的卡片，气泡平滑隐藏。
- **优势**：**不需要让用户的视线频繁跳跃至右侧栏查看底层调试信息。** 诊断数据和心跳灯物理位置紧密贴合，提供了极佳的“就地探测（Contextual Inspect）”体验。

### 3. 各模块气泡诊断数据规范 (M1–M8 Diagnostic Spec)

当用户点击底部卡片时，吸附气泡内展示的标准调试指标规范如下：

| 模块编码 | 模块定位 (Role) | 气泡内诊断参数规范 (Diagnostic Parameters) |
| :--- | :--- | :--- |
| **M1** | **ODD / 包络状态机** | ① 当前包络控制域判定（开阔水域/港内）；② ODD 安全限制包络健康系数（SFF %）；③ 风速/水深环境诊断实测值；④ 硬件强行覆盖信号状态。 |
| **M2** | **全局航线规划器** | ① 全局计划航线名称；② 实步横向偏航偏差值（XTE）；③ 下一个转向路点地理空间坐标；④ 全局插值平滑数学模型（如 B-Spline）。 |
| **M3** | **任务路线跟踪器** | ① 航次时空任务执行状态阶段；② 累积航程进度百分比（已驶海里/总海里）；③ 巡航计划航速与实步航速对齐误差；④ 航段到港 ETA 延误度（秒）。 |
| **M4** | **IvP 行为仲裁器** | ① 周期求解解算延时（ms）；② 顶层最高评分决策活跃行为（Active Behavior）；③ 避碰与其他并存行为（航线跟踪、经济速度）的效用价值（Utility）分配权重矩阵。 |
| **M5** | **BC-MPC 战术规划** | ① 动态空间避碰生成候选轨迹曲线总数；② 不确定性偏差适应误差带包络（Uncertainty Bands）状态；③ 最优轨迹代数代价总分（Cost）；④ 避碰安全代价、操舵急动代价等各个维度 Cost 分解值。 |
| **M6** | **COLREGs 推理树** | 呈现结构清晰、带百分比置信度（Confidence）的决策推理树结构：[1] 瞭望域 Rule 5 $\rightarrow$ [2] 会遇场景划分 $\rightarrow$ [3] 责任归属让路 $\rightarrow$ [4] 行动优先级 $\rightarrow$ [5] 行动时机合规判断。 |
| **M7** | **SOTIF 安全监督器**| ① 冗余安全判定状态（Doer-Checker 轨迹偏差是否超限）；② 碰撞险度参数度量值（CRI）；③ 走锚、越界、动力学过载超限指标；④ 降级最小风险策略（MRM）备用链触发状态。 |
| **M8** | **HMI 报警发布器** | ① 人机报警同步握手状态；② 操作交互总线时延；③ 全局警报优先级级别判定；④ CCS HMI 规约完整性校验。 |

## 🎨 五、 地图中心视口层与空间几何投影

中心地图大盘作为整个仿真的核心，负责将物理空间与算法空间的几何数据直接投影在底图上，避免侧边栏被低效的数值表格占满。

### 1. 本船/目标物物理投影（Operator Focus）
- **本船指示牌**：包含艏向（HDG）三角形方向尖端；悬浮本船数据牌（HDG、COG、SOG、ROT）通过反向旋转算法在缩放或转向时永远保持直立阅读。
- **航速预测矢量线**：基于 COG 与实时 SOG 的 6 分钟运动距离预测线。
- **避碰安全圈**：本船周围 0.5 nm（安全红线）及 1.0 nm（预警黄线）虚线圈。
- **浅滩搁浅高亮红区**：周期扫描浅滩几何数据与本船吃水/航向的交集，将有碰撞搁浅风险的陆地/浅滩区域以 `40%` 透明度红色闪烁高亮。

### 2. 算法诊断空间投影（Engineer Focus - 仅在打开右侧栏/调试视角下可见）
- **候选轨迹簇 (MpcTrajectoryLayer)**：将 M5 生成的 13 条未来战术候选路径曲线直接渲染在海图上，展示算法解算的收敛与探索程度。
- **避碰风险梯度场 (IvpRiskGradientLayer)**：将 M4 计算生成的避碰风险梯度场（Ivp Contributions）以微网格伪彩色热力图渲染在海图背景，揭示海域内危险能量的分布。
- **规则避碰扇区 (ColregsSectors)**：以不同颜色扇区划分交叉、追越、对遇等规则判定区间。

后续工程实装前，需基于此原型对以下人机交互指标进行检验：

2.  **气泡吸附指向精度**：地图视口尺寸拉伸缩放时，气泡三角尖端在屏幕上的横向位置必须与被点击的 M1-M8 脉搏卡片几何中心实时对齐。
3.  **刷新率新鲜度**：底部卡片的心跳更新频率与时延的周期性更新速度需与各模块（M1-M8）的真实 ROS 发布主题保持同频（1 Hz - 10 Hz）。
