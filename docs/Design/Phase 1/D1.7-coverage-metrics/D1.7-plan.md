```markdown
## §5 6 维度结构化 COLREGs 评分 Rubric

### 5.1 评分架构（Hagen 2022 [R33] + Woerner 2019 [R34]）

本评分体系采用"PASS/FAIL 二元 verdict + 6 维度连续评分"双轨并存模式：

- **PASS/FAIL verdict**: 判定当前 encounter 是否满足最低安全要求（min CPA ≥ 0.27NM AND no Rule violation = "full violation"）——二元，用于 gate 判断
- **6 维度连续评分**: 对决策质量进行细粒度量化——连续，用于 CCS surveyor 论据 + 算法改进反馈

| # | 维度 | 英文名 | 权重 | 分值范围 | 含义 |
|---|---|---|---|---|---|
| 1 | 安全评分 | Safety score (w_s) | **0.30** | [0, 1] | CPA 与安全阈值的距离；1.0 = 完全安全，0 = 碰撞 |
| 2 | 规则合规评分 | Rule compliance score (w_r) | **0.25** | [0, 1] | 各适用 COLREG 规则的平均合规度 {full=1.0 / partial=0.5 / violated=0.0} |
| 3 | 延迟惩罚 | Delay penalty (p_d) | **0.12** | [0, ∞) | 决策启动相比 TCPA 阈值的延迟（线性扣分） |
| 4 | 动作幅度惩罚 | Action magnitude penalty (p_m) | **0.08** | [0, 1] | 转向幅度偏离 ideal range [30°, 90°] 的 2nd-order penalty |
| 5 | 阶段得分 | Phase score (w_p) | **0.15** | [0, 1] | 让路船 (1.0) / 直航船 (0.5) / in extremis (0.0) |
| 6 | 轨迹合理性 | Trajectory implausibility | **0.10** | [0, 1] | 物理可行性检查（曲率/加速度上限），防 RL "作弊" |

**总得分公式**:
```
total_score = w_s × safety + w_r × rule − p_delay − p_mag + w_p × phase + w_plaus × plausibility

weighted_total = 0.30 × safety + 0.25 × rule
                 − clamp(0, 1, delay_raw) × 0.12
                 − clamp(0, 1, mag_raw) × 0.08
                 + 0.15 × phase
                 + 0.10 × plausibility
```

**PASS/FAIL verdict 独立判断**（与 weighted_total 并存）:
```
PASS = (min_CPA ≥ CPA_target) AND (all applicable rules ∈ {full, partial}) AND (no grounding)
FAIL = otherwise
```

### 5.2 权重设计依据

| 权重 | 初值 | 来源 | 校准计划 |
|---|---|---|---|
| w_s = 0.30 | 2026-05-20 | Hagen 2022 §II.C 安全优先级；Woerner 2019 §Table I safety 首项 | HAZID RUN-001 校准（8/19）；D3.6 1000 场景后 sensitivity analysis |
| w_r = 0.25 | 2026-05-20 | Hagen 2022 §IV "Rule compliance as constraint, not objective" | 同 w_s |
| w_p = 0.15 | 2026-05-20 | Woerner 2019 §Table II phase differentiation | 同 w_s |

**推翻信号**: 若 CCS《智能船舶规范 2024》§9.1 要求权重按 CCS 条款重构 → D1.7 权重退为内部参考 + 外发按 CCS 条款重标注

**置信度**: 🟡 Medium（维度结构 NTNU/MIT 学术圈公认；具体权重值需 D3.6 校验）
```

### 5.4 Python 伪代码算法规约

# D2.4 实现时的算法参考 — 本 D1.7 仅出规约，不由本 D 实装

from dataclasses import dataclass
from typing import Dict, List, Tuple
import math

@dataclass
class COLREGRubricScore:
    """6-dimension per-timestep score for one encounter."""

    rule_compliance: float  # [0, 1]
    delay_penalty: float    # raw, [0, ∞)

    plausibility: float  # [0, 1]
    weighted_total: float  # [0, 1]
    pass_fail: bool       # PASS/FAIL verdict (independent)

DEFAULT_WEIGHTS: Dict[str, float] = {
    "safety": 0.30,
    "rule_compliance": 0.25,
    "delay_penalty": 0.12,
    "action_mag_penalty": 0.08,
    "phase": 0.15,
    "plausibility": 0.10,
}

CPA_TARGET_NM: float = 0.27  # [TBD-HAZID-CPA-001]

def score_safety(cpa_nm: float) -> float:
    """Safety score: linear decay from 1.0 at CPA ≥ target to 0.0 at CPA = 0."""
    return min(1.0, max(0.0, cpa_nm / CPA_TARGET_NM))

def score_rule_compliance(rule_states: Dict[str, str]) -> float:
    """Per-rule compliance → average across applicable rules."""
    score_map = {"full": 1.0, "partial": 0.5, "violated": 0.0}
    if not rule_states:
        return 1.0
    return sum(score_map.get(v, 1.0) for v in rule_states.values()) / len(rule_states)

def score_delay_penalty(t_action_s: float, t_target_s: float, coeff: float = 0.01) -> float:
    """Linear delay penalty: max(0, t_action - t_target) × λ."""
    return max(0.0, t_action_s - t_target_s) * coeff

def score_action_magnitude(rudder_deg: float) -> float:
    """Second-order penalty for deviation from [30°, 90°] ideal range."""
    if abs(rudder_deg) < 30.0:
        return ((30.0 - abs(rudder_deg)) / 30.0) ** 2
    if abs(rudder_deg) > 90.0:
        return ((abs(rudder_deg) - 90.0) / 30.0) ** 2
    return 0.0

def score_phase(behavior: str) -> float:
    """Phase score: give_way=1.0, stand_on=0.5, in_extremis=0.0"""
    return {"give_way": 1.0, "stand_on": 0.5, "in_extremis": 0.0, "transit": 1.0}.get(behavior, 0.5)

def score_plausibility(curvature: float, accel_ms2: float,
                       kappa_max: float = 0.01, accel_max_ms2: float = 2.0) -> float:
    """Physics plausibility: curvature and acceleration must be within vessel limits."""
    ek = max(0.0, abs(curvature) - kappa_max) / kappa_max if kappa_max > 0 else 0.0
    ea = max(0.0, abs(accel_ms2) - accel_max_ms2) / accel_max_ms2 if accel_max_ms2 > 0 else 0.0
    return 1.0 - max(ek, ea)

def compute_verdict(min_cpa_nm: float, rule_states: Dict[str, str]) -> bool:
    """PASS/FAIL binary verdict (independent of weighted score)."""
    return (min_cpa_nm >= CPA_TARGET_NM and
            all(v in ("full", "partial") for v in rule_states.values()))

### 6.1 定位

### 6.3 抽样方法对比

| 方法 | 适用场景 | 优势 | 劣势 |
|---|---|---|---|
| **Latin Hypercube (LHS)** | 参数独立时 | 每参数边际分布精确；比纯 MC 快 10× 收敛 | 参数相关时需 Iman-Conover 修正 |

### 6.4 COLREG Geometric Filter（Hassani 2022 [R32] 方法）

每次 LHS/Sobol sample 后，通过 COLREG geometric filter 过滤掉无碰撞风险的场景：

5. COLREG 分类: bearing → sector → Rule label (14/15/13)

"""D1.7 1100-cell COLREG coverage heatmap generator.

Reads traceability.csv (from D1.3.2.1 22 Imazu output) and generates
an HTML heatmap showing which cells of the 1100-cell cube are covered.

Usage:
    python tools/sil/scenarios_coverage.py \
        --traceability reports/traceability.csv \
        --output reports/coverage_heatmap.html
"""
from __future__ import annotations

import argparse
from datetime import datetime, timezone
from pathlib import Path
from coverage_cube import CoverageCube, COLREG_RULES, ODD_ZONES, TOTAL_CELLS


def generate_heatmap(
    traceability_csv: Path,
    output_html: Path,
) -> None:
    cube = CoverageCube.load_from_csv(str(traceability_csv))
    matrix = cube.to_heatmap_matrix()
    cells_lit = cube.cells_lit()

    html = _render_heatmap_html(matrix, cells_lit)
    output_html.write_text(html, encoding="utf-8")


def _render_heatmap_html(
    matrix: list[list[int]],
    cells_lit: int,
) -> str:
    import textwrap

    # Build color-coded HTML table
    rows_html = []
    for i, rule in enumerate(COLREG_RULES):
        cells = ""
        for j, odd in enumerate(ODD_ZONES):
            count = matrix[i][j]
            max_per_cell = 25  # 5 disturbance × 5 seed
            intensity = int(255 * (1.0 - count / max_per_cell)) if max_per_cell > 0 else 255
            color = f"rgb({intensity}, {255 - intensity // 2}, 100)"
            cells += f'<td style="background:{color};color:#fff;text-align:center;padding:6px">{count}/{max_per_cell}</td>'
        rows_html.append(f"<tr><td style='font-weight:bold'>{rule}</td>{cells}</tr>")

    return textwrap.dedent(f"""\
    <!DOCTYPE html>
    <html><head><meta charset="utf-8">
    <title>COLREGs Coverage Cube Heatmap</title>
    <style>
      body {{ font-family: -apple-system, sans-serif; margin: 20px; }}
      table {{ border-collapse: collapse; }}
      th, td {{ border: 1px solid #333; padding: 8px; }}
      th {{ background: #444; color: #fff; }}
    </style></head><body>
    <h1>1100-Cell COLREGs Coverage Heatmap</h1>
    <p>Generated: {datetime.now(tz=timezone.utc).isoformat()}</p>
    <p>Cells lit: <strong>{cells_lit}</strong> / {TOTAL_CELLS} ({cells_lit/TOTAL_CELLS*100:.1f}%)</p>
    <table>
    <tr><th>Rule</th>{''.join(f'<th>{o}</th>' for o in ODD_ZONES)}</tr>
    {''.join(rows_html)}
    </table>
    <p><em>Cell format: lit_cells / 25 (5 disturbance × 5 seed)</em></p>
    <p><em>Green = high coverage; Yellow = medium; Red = low / uncovered</em></p>
    </body></html>
    """)


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("--traceability", required=True, type=Path)
    ap.add_argument("--output", required=True, type=Path)
    args = ap.parse_args()
    generate_heatmap(args.traceability, args.output)
