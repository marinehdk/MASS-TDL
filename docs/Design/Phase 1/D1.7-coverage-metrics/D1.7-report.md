## 7. Lessons Learned

1. **文档先行优于 stub 迭代**：D1.7 证明，先出 plan（Task 1–5 拆分）→ 按 plan 批量产出完整章节 比逐节填充 stub 高效 3–5×
2. **Per-rule 子准则表是下游耦合点**：§5.3 的 13 条子准则表被 D2.4 实现直接引用为代码级规约，证明 plan 阶段的"到可直接实现的精度"要求是合理的前置条件
3. **热图工具需要 traceability.csv 预处理管道**：当前 traceability.csv 由手工脚本从 YAML 提取生成；D1.3.2.1 batch_runner → coverage_reporter 的自动化管线是 DEMO-2 的关键增强点
