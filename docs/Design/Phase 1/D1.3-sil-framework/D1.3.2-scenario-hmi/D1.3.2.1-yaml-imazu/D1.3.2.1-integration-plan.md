**Context:** This is the **critical DEMO-1 blocker**. The `lifecycle_bridge.configure()` currently calls `_change_state(TRANSITION_CONFIGURE)` without ever reading the scenario YAML. The `ship_dynamics_node` and `target_vessel_node` then use their hardcoded default params (30°N, 122°E, zero targets). This task makes `configure(scenario_id)` actually inject scenario-specific initial positions.

**Approach:**
1. In `configure(scenario_id)`, before calling the ROS2 CONFIGURE transition:
   a. Construct file path: `scenarios/IMAZU标准测试/imazu-{id}.yaml`
   b. Parse YAML with `yaml.safe_load`
   c. Extract `ownShip.initial.position.{latitude, longitude, cog, sog, heading}`
   d. Extract `targetShips[].initial.{position, cog, sog}`
   e. Extract `environment.{wind.speed_mps, wind.dir_deg, current.speed_mps, current.dir_deg}`
   f. Convert lat/lon to ENU offsets via `geo_utils.latlon_to_enu()` — but for ROS2 params, we pass the actual lat/lon values (ship_dynamics node does its own conversion)
   g. Set ROS2 parameters on `ship_dynamics_node`: `origin_lat`, `origin_lon` (from ownShip initial lat/lon), `psi0` (from ownShip heading_deg), `u0` (from sog knots→m/s)
   h. Set ROS2 parameter on `target_vessel_node`: `default_targets_json` as JSON array of target objects
   i. Then fire the CONFIGURE transition as before

### Key Design Decision

The ship_dynamics MMG model uses NED coordinates (x_m, y_m). We make the ownShip's initial position the **geo_origin** (x=0, y=0), and express target positions as offsets from that origin. This matches the scenario design: OS is always at origin, targets are at ΔN/ΔE offsets.

### Scenario YAML structure (v3.0 camelCase, actual on-disk format):
```yaml
ownShip:
  initial:
    position:
      latitude: 63.44    # Norwegian Sea
      longitude: 10.38
    cog: 0.0
    sog: 10.0            # knots
    heading: 0.0
targetShips:
  - id: ts1
    static:
      mmsi: 100000001
    initial:
      position:
        latitude: 63.557451
        longitude: 10.38
      cog: 180.0
      sog: 10.0
      heading: 180.0
environment:
  wind: {dir_deg: 0.0, speed_mps: 0.0}
  current: {dir_deg: 0.0, speed_mps: 0.0}
  visibility_nm: 5.4
```

### ROS2 param mapping

| YAML field | ROS2 param (ship_dynamics_node) | Description |
|---|---|---|
| `ownShip.initial.position.latitude` | `origin_lat` | Geo origin lat (deg) |
| `ownShip.initial.position.longitude` | `origin_lon` | Geo origin lon (deg) |
| `ownShip.initial.heading` | `psi0` | Initial heading in math convention (π/2 − rad(heading_deg)) |
| `ownShip.initial.sog` (knots) | `u0` | Initial surge speed in m/s (kn × 0.514444) |

| YAML field | ROS2 param (target_vessel_node) | Description |
|---|---|---|
| `targetShips[]` array | `default_targets_json` | JSON array of `{mmsi, lat, lon, heading_deg, sog_kn}` |

```python
def test_default_origin():
    lat, lon = default_origin()
    assert lat == 63.0
    assert lon == 5.0


def test_own_ship_at_origin():
    """OS at origin → ENU (0, 0)."""
    n, e = latlon_to_enu(63.0, 5.0, 63.0, 5.0)
    assert abs(n) < 1e-6
    assert abs(e) < 1e-6


def test_target_north_of_os():
    """Target at standard Imazu test anchor (63.44°N, 10.38°E).
    OS is at (63.44, 10.38) → target is at (63.557451, 10.38).
    Δlat = 0.117451° → ΔN ≈ 13060 m.
    """
    origin = (63.44, 10.38)
    ts_lat, ts_lon = 63.557451, 10.38
    dn, de = latlon_to_enu(*origin, ts_lat, ts_lon)
    # Expected: ~13060 m North, ~0 m East
    assert abs(dn - 13060.0) < 5.0   # < 5 m tolerance
    assert abs(de) < 2.0


def test_roundtrip_imazu01_target():
    """Convert target position → ENU → back to lat/lon, verify < 1 m error."""
    origin = (63.44, 10.38)
    ts_lat, ts_lon = 63.557451, 10.38
    dn, de = latlon_to_enu(*origin, ts_lat, ts_lon)
    lat2, lon2 = enu_to_latlon(*origin, dn, de)
    # Roundtrip error
    dn2, de2 = latlon_to_enu(*origin, lat2, lon2)
    assert abs(dn2 - dn) < 1.0
    assert abs(de2 - de) < 1.0


def test_heading_to_psi_math():
    """Heading 0° (North) → psi_math = π/2; heading 90° (East) → psi_math = 0."""
    def psi_math(heading_deg):
        return math.pi / 2.0 - math.radians(heading_deg)
    assert abs(psi_math(0.0) - math.pi / 2.0) < 1e-9
    assert abs(psi_math(90.0) - 0.0) < 1e-9
    assert abs(psi_math(180.0) + math.pi / 2.0) < 1e-9
```

```python
        self._state = LifecycleState.INACTIVE
```

```python
def _inject_scenario_params(yaml_path: Path, node: Node) -> None:
    """Parse scenario YAML and set ROS2 parameters on SIL lifecycle nodes.
    
    Reads maritime-schema v3.0 camelCase YAML.
    Sets params on ship_dynamics_node and target_vessel_node via
    ROS2 parameter service BEFORE those nodes are configured.
    
    Args:
        yaml_path: Path to scenario YAML file.
        node: The LifecycleBridge node (for param client).
    
    Raises:
        ValueError: If YAML is malformed or missing required fields.
    """
    data = yaml.safe_load(yaml_path.read_text(encoding="utf-8"))
    
    # ── Own ship params → ship_dynamics_node ──────────────────────
    own = data["ownShip"]
    own_init = own["initial"]
    own_pos = own_init["position"]
    own_lat = float(own_pos["latitude"])
    own_lon = float(own_pos["longitude"])
    own_sog_kn = float(own_init["sog"])
    own_heading_deg = float(own_init.get("heading", own_init["cog"]))
    
    # Convert nautical heading (CW from North, deg) → math convention (CCW from East, rad)
    own_psi_rad = math.pi / 2.0 - math.radians(own_heading_deg)
    # Convert SOG knots → m/s
    own_u_mps = own_sog_kn * 0.514444
    
    # Set params on ship_dynamics_node
    _set_ros_param(node, "ship_dynamics_node", "origin_lat", own_lat)
    _set_ros_param(node, "ship_dynamics_node", "origin_lon", own_lon)
    _set_ros_param(node, "ship_dynamics_node", "psi0", own_psi_rad)
    _set_ros_param(node, "ship_dynamics_node", "u0", own_u_mps)
    _set_ros_param(node, "ship_dynamics_node", "x0", 0.0)
    _set_ros_param(node, "ship_dynamics_node", "y0", 0.0)
    
    _log.info("Injected own_ship params: lat=%.4f lon=%.4f psi=%.4f u=%.3f m/s",
              own_lat, own_lon, own_psi_rad, own_u_mps)
    
    # ── Target ship params → target_vessel_node ───────────────────
    targets_json = []
    for ts in data.get("targetShips", []):
        ts_init = ts["initial"]
        ts_pos = ts_init["position"]
        ts_mmsi = ts.get("static", {}).get("mmsi", 100000000 + len(targets_json) + 1)
        ts_sog_kn = float(ts_init["sog"])
        ts_heading = float(ts_init.get("heading", ts_init["cog"]))
        targets_json.append({
            "mmsi": int(ts_mmsi),
            "lat": float(ts_pos["latitude"]),
            "lon": float(ts_pos["longitude"]),
            "heading_deg": ts_heading,
            "sog_kn": ts_sog_kn,
            "mode": "replay",
        })
    
    _set_ros_param(node, "target_vessel_node", "default_targets_json",
                   json.dumps(targets_json))
    
    _log.info("Injected %d target vessel(s)", len(targets_json))
    
    # ── Environment params → env_disturbance_node ─────────────────
    env = data.get("environment", {})
    wind = env.get("wind", {})
    current = env.get("current", {})
    if wind:
        _set_ros_param(node, "env_disturbance_node", "wind_speed_mps",
                       float(wind.get("speed_mps", 0.0)))
        _set_ros_param(node, "env_disturbance_node", "wind_direction",
                       float(wind.get("dir_deg", 0.0)))
    if current:
        _set_ros_param(node, "env_disturbance_node", "current_speed_mps",
                       float(current.get("speed_mps", 0.0)))
        _set_ros_param(node, "env_disturbance_node", "current_direction",
                       float(current.get("dir_deg", 0.0)))
```

```python
def _set_ros_param(node: Node, target_node_name: str, param_name: str, value) -> None:
    """Set a ROS2 parameter on a target node using the parameter client.
    
    Best-effort: logs warning but does not raise on failure.
    The node will read the param during its own on_configure() callback.
    """
    try:
        from rclpy.parameter import Parameter
        param_client = node._sil_param_clients.get(target_node_name)
        if param_client is None:
            # Create param client on first use
            from rcl_interfaces.srv import SetParameters
            param_client = node.create_client(
                SetParameters,
                f"/{target_node_name}/set_parameters",
            )
            # Store for reuse
            if not hasattr(node, '_sil_param_clients'):
                node._sil_param_clients = {}
            node._sil_param_clients[target_node_name] = param_client
        
        if not param_client.wait_for_service(timeout_sec=1.0):
            _log.debug("Parameter service /%s/set_parameters not ready yet", target_node_name)
            # Fallback: set param on the LifecycleBridge node itself
            # (lifecycle nodes share param server in ROS2)
            from rclpy.parameter import Parameter
            if not hasattr(node, f"_sil_param_{target_node_name}_init"):
                # Use the global parameter server approach
                parameters = [Parameter(param_name, Parameter.Type.DOUBLE, float(value)).to_parameter_msg()]
                node.set_parameters(parameters)
                return
            return
        
        param = Parameter(param_name, value=value)
        req = SetParameters.Request()
        req.parameters = [param.to_parameter_msg()]
        
        future = param_client.call_async(req)
        # Don't block — the node will read params during its own on_configure
        _log.debug("Param request sent: %s.%s = %s", target_node_name, param_name, value)
    except Exception as exc:
        _log.warning("Could not set param %s on %s: %s", param_name, target_node_name, exc)
```

> **Note on ROS2 param mechanism:** In ROS2, lifecycle nodes read parameters during `on_configure()`. The approach above sets params on the LifecycleBridge node's own parameter server. When the target nodes (ship_dynamics, target_vessel) call `on_configure()`, they use `declare_parameter(name, default)` which picks up params already set externally. This works because ROS2 params are node-scoped — we need to set them on the **target node's** parameter server, not the bridge's.

> **Revised approach for ROS2 Humble:** The simplest reliable method in ROS2 Humble is to use the `ros2 param` mechanism. In `lifecycle_bridge.configure()`, we construct a param YAML file and use `subprocess.run(["ros2", "param", "load", ...])`. However, for maximum simplicity and to avoid subprocess, we use the ROS2 parameter client API directly on the target node names.

```python
"""Python cerberus validator for maritime-schema v3.0 scenario YAML."""
from pathlib import Path
import cerberus
import yaml

_SCHEMA_PATH = Path(__file__).parent / "cerberus_schema" / "fcb_scenario_v3.yaml"


def validate_yaml(data: dict) -> None:
    """Validate maritime-schema v3.0 data dict. Raises ValueError on failure."""
    schema = yaml.safe_load(_SCHEMA_PATH.read_text(encoding="utf-8"))
    v = cerberus.Validator(schema, allow_unknown=True)
    if not v.validate(data):
        errors = v.errors
        raise ValueError(f"Schema validation failed: {errors}")


def validate_file(path: Path) -> None:
    """Validate a YAML file against the schema. Raises ValueError on failure."""
    data = yaml.safe_load(path.read_text(encoding="utf-8"))
    validate_yaml(data)
```

```cpp
/// Standalone C++ CLI: validate scenario YAML against cerberus schema.
///
/// Usage: ./validate_scenario <schema.yaml> <scenario.yaml>
/// Exit:  0 = valid, 1 = invalid (errors to stderr), 2 = usage error
///
/// Uses cerberus-cpp compatible subset of schema:
///   type, required, min, max, allowed, schema
///
/// Schema file: tools/sil/cerberus_schema/fcb_scenario_v3.yaml
#include "cerberus-cpp/cerberus.hpp"
#include <yaml-cpp/yaml.h>
#include <iostream>
#include <string>

int main(int argc, char** argv) {
    if (argc != 3) {
        std::cerr << "Usage: " << argv[0] << " <schema.yaml> <scenario.yaml>\n";
        return 2;
    }

    try {
        auto schema   = YAML::LoadFile(argv[1]);
        auto document = YAML::LoadFile(argv[2]);

        cerberus::Validator validator(schema);
        if (validator.validate(document)) {
            return 0;  // OK
        }

        // Print all validation errors to stderr
        for (const auto& err : validator.errors()) {
            std::cerr << err << "\n";
        }
        return 1;  // Invalid
    } catch (const std::exception& e) {
        std::cerr << "Error: " << e.what() << "\n";
        return 2;  // Fatal error
    }
}
```

```python
from pathlib import Path
from typing import Callable

# Default scenario directories for 32-scenario batch
DEFAULT_SCENARIO_DIRS = [
    Path("scenarios/IMAZU标准测试"),
    Path("scenarios/COLREGs测试"),
]

def discover_scenarios(dirs: list[Path] | None = None) -> list[Path]:
    """Glob all *.yaml files from given dirs, excluding schema files.
    
    Args:
        dirs: List of directories to search. Defaults to 32-scenario set.
    Returns:
        Sorted list of absolute paths to scenario YAML files.
    """
    if dirs is None:
        dirs = DEFAULT_SCENARIO_DIRS
    results = []
    for d in dirs:
        if d.exists():
            results.extend(sorted(
                f for f in d.glob("*.yaml")
                if not f.name.startswith("schema")
            ))
    return results
```

```python
        "total_wall_clock_s": sum(r["wall_clock_s"] for r in results),
    }

def _write_arrow_summary(rows: list[dict], path: Path) -> None:
    table = pa.Table.from_pylist(rows, schema=SUMMARY_SCHEMA)
    with pa.OSFile(str(path), "wb") as sink:
        with ipc.new_file(sink, SUMMARY_SCHEMA) as writer:
            writer.write_table(table)

def _write_arrow_trajectories(rows: list[dict], path: Path) -> None:
    table = pa.Table.from_pylist(rows, schema=TRAJECTORY_SCHEMA)
    with pa.OSFile(str(path), "wb") as sink:
        with ipc.new_file(sink, TRAJECTORY_SCHEMA) as writer:
```

```python
def _infer_rule_label(scenario_id: str, metadata: dict | None = None) -> str:
    """Infer COLREGs rule from scenario metadata or ID pattern.
    
    Priority:
    1. metadata.encounter.rule (if present)
    2. scenario_id pattern matching
    3. "Unknown"
    """
    if metadata:
        enc = metadata.get("encounter", {})
        rule = enc.get("rule", "")
        if rule:
            return rule
    # Fallback: ID pattern
    sid_lower = scenario_id.lower()
    if "ho" in sid_lower or "head" in sid_lower:

    if "cr-gw" in sid_lower or "cr_gw" in sid_lower or "crossing" in sid_lower:

    if "cr-so" in sid_lower or "cr_so" in sid_lower:
        return "Rule15"
    if "ot" in sid_lower or "overtaking" in sid_lower:
        return "Rule13"
    if "ms" in sid_lower:
        return "Multi-Ship"  # Dominant rule varies per encounter
```

```bash
#!/bin/bash
# Check Imazu-22 scenario hashes against frozen manifest.
# Usage: bash tools/ci/check-imazu22-hash.sh
# Exit 0 = all hashes match, Exit 1 = mismatch detected
set -euo pipefail

MANIFEST="scenarios/.imazu22_sha256_manifest.yaml"
SCENARIOS_DIR="scenarios/IMAZU标准测试"

if [[ ! -f "$MANIFEST" ]]; then
    echo "ERROR: Manifest not found: $MANIFEST"
    exit 2
fi

all_ok=true
while IFS=: read -r filename expected_hash; do
    # Skip non-file lines
    [[ "$filename" == "collection" ]] && continue
    [[ "$filename" == "schema_version" ]] && continue
    [[ -z "$filename" ]] && continue
    
    filename=$(echo "$filename" | xargs)  # trim whitespace
    expected_hash=$(echo "$expected_hash" | xargs)
    
    if [[ ! -f "$SCENARIOS_DIR/$filename" ]]; then
        echo "FAIL: File not found: $filename"
        all_ok=false
        continue
    fi
    
    actual_hash=$(sha256sum "$SCENARIOS_DIR/$filename" | awk '{print $1}')
    if [[ "$actual_hash" != "$expected_hash" ]]; then
        echo "FAIL: $filename hash mismatch"
        echo "  Expected: $expected_hash"
        echo "  Actual:   $actual_hash"
        all_ok=false
    fi
done < <(python3 -c "
import yaml
m = yaml.safe_load(open('$MANIFEST'))
for fname, h in m.get('files', {}).items():
    print(f'{fname}: {h}')
")

if $all_ok; then
    echo "OK: All 22 Imazu scenario hashes match MANIFEST"
    exit 0
else
    echo "FAIL: Hash mismatch detected"
    exit 1
fi
```
