# D1.3.2 SIL↔L3 内核集成补全计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 关闭 DEMO-1 (2026-06-15) 端到端实数据链路 — 让 SIL 仿真容器内的 9 个 Python sim 节点与 L3 内核 M1-M8 C++ 节点在同一 ROS2 domain 内通信，前端 `useFoxgloveLive` 消费真实 M8 SAT-1 数据而非 `demo_telemetry` fallback。

**Architecture:** 采用 **ros2_topic_bridge 桥接方案**（非侵入式）— L3 内核 topic 全部硬编码在 C++ 源码中不可参数化，DEMO-1 阶段不修改 M1-M8 源码。通过一个轻量 Python bridge node 在 `/sil/*` 与 `/fusion/*`/`/l3/m{N}/*` 之间双向中继消息。Bridge node 追加到 `sil_entrypoint.sh` 中，在 sil-nodes 容器内运行（与 sim 节点共享 DDS domain）。

**Tech Stack:** ROS2 Humble (rclpy/rclcpp), Docker, bash, python3, ros2 topic tools, colcon, CycloneDDS

**关键发现（探索确认）：**
- L3 内核所有 topic 名称在 C++ 源码中 **硬编码为字符串字面量**（无 `declare_parameter` 可覆盖）
- M5 Mid-MPC 使用 `/m2/` 等短前缀（无 `/l3/`），与其他模块的 `/l3/m2/` 标准不一致 → **5 个内部 topic 不匹配**
- M7 订阅 `/l3/m2/odd_state` 而非 `/l3/m1/odd_state`（拼写错误）
- 前端 `useFoxgloveLive.ts` 只订阅 `/sil/*` 命名空间下的 11 个 topic

```
  前端 ── useFoxgloveLive 读到 /sil/* 实数据（own_ship → SIM, behavior_plan → M4, scoring → M7）
```

## 前置决策：Topic 桥接方式

### ❌ 方案 A：修改 M1-M8 源码 topic 字符串
- 优势：无额外进程
- 劣势：L3 内核源码变更风险高；需同时修复 5 个内部 topic 不匹配；DEMO-1 后回滚成本大；与架构文档 §15.2 接口契约表不一致

### ✅ 方案 B：ros2_topic_bridge 节点（推荐，本 plan 采用）
- 优势：L3 内核零修改；bridge 节点独立可测；DEMO-1 后可通过 `SIL_L3_ENABLE=0` 完全旁路；topic 映射集中管理在一处
- 劣势：多一个 Python 进程（~5 MB 内存，可忽略）
- 风险：bridge 引入 ~1-5ms 额外延迟（sil-nodes 内同进程 DDS，可接受）

### 前置修复：5 个 L3 内部 topic 不匹配

在编写 bridge 之前，必须先修复 L3 内核内部 topic 不匹配（否则 M4→M5→M7/M8 链路仍然不通）：

| # | 文件 | 当前值 | 应改为 | 影响 |
|---|---|---|---|---|
| F1 | `m5_tactical_planner/src/mid_mpc/mid_mpc_node.cpp` | `/m2/own_ship_state` | `/l3/m2/world_state`（或走 bridge `/sil/own_ship_state`）| M5 收不到 M2 世界状态 |
| F2 | `m5_tactical_planner/src/mid_mpc/mid_mpc_node.cpp` | `/m2/tracked_targets` | `/l3/m2/world_state`（world_state 已含 targets）| M5 收不到目标 |

## Task 1: Topic Naming Decision 文档

**文件：**
- 新建：`docs/Design/Phase 1/D1.3-sil-framework/D1.3.2-scenario-hmi/topic-naming-decision.md`

**职责：** 编写一份 topic 命名仲裁文档，列 SIL 侧 `/sil/*` 12 个 topic 与 L3 期望 `/fusion/*` `/l3/m{N}/*` 的逐项映射，作为 bridge 实现的唯一权威参考。

### 1.1 确定 bridge 输入→输出映射表

根据 SIL 仿真拓扑和 L3 内核 topic 拓扑，需要桥接的 topic 对如下：

#### SIL → L3（仿真数据输入 L3 内核）

| 桥接方向 | SIL 侧 Topic（源） | L3 侧 Topic（目标） | 消息类型 | 消费模块 |
|---|---|---|---|---|
| **own_ship_state** | `/sil/own_ship_state` | `/fusion/own_ship_state` | `sil_msgs/OwnShipState` → `l3_external_msgs/FilteredOwnShipState` | M1, M2 |
| **target_vessel_state** | `/sil/target_vessel_state` | `/fusion/tracked_targets` | `sil_msgs/TargetVesselState` → `l3_external_msgs/TrackedTargetArray` | M2 |
| **environment** | `/sil/environment` | `/fusion/environment_state` | `sil_msgs/EnvironmentState` → `l3_external_msgs/EnvironmentState` | M1, M2 |
| **sim_clock** | `/sim_clock` | `/sim_clock` | `builtin_interfaces/Time`（透传）| 全部 M 节点 |

> ⚠️ **类型不匹配**: `sil_msgs/OwnShipState` (flat: lat/lon/heading/sog/cog/rot/u/v/r/rudder/throttle) 与 `l3_external_msgs/FilteredOwnShipState` (含 covariance + EKF 滤波后状态) 结构不同。Bridge 需要做字段适配（见 Task 5）。

#### L3 → SIL（L3 决策输出回 SIL）

| 桥接方向 | L3 侧 Topic（源） | SIL 侧 Topic（目标） | 消息类型 | 消费方 |
|---|---|---|---|---|
| **actuator_cmd** | `/m5/avoidance_plan` | `/sil/control_cmd` | `l3_msgs/AvoidancePlan` → `ship_sim_interfaces/ActuatorCmd` | ship_dynamics_node |
| **module_pulse** | `/l3/m7/heartbeat` + 各 M 节点 | `/sil/module_pulse` | 多源 → `sil_msgs/ModulePulse` | 前端 ConningBar |
| **asdr_event** | `/l3/asdr/record` | `/sil/asdr_event` | `l3_msgs/ASDRRecord` → `sil_msgs/ASDREvent` | 前端 ASDR 日志 |
| **scoring** | `/sil/scoring` | `/sil/scoring` | **透传**（scoring_node 已在 sim 容器内）| 前端 ScoringRow |
| **lifecycle_status** | `/sil/lifecycle_status` | `/sil/lifecycle_status` | **透传**（lifecycle_mgr 已在 sim 容器内）| 前端 |

#### M8 SAT-1 到前端

M8 HMI/Transparency Bridge 聚合所有模块的 `/l3/sat/data`，发布 `/l3/m8/ui_state`。需桥接到前端可读的 topic：

| L3 侧 Topic（源） | SIL 侧 Topic（目标） | 消费方 |
|---|---|---|
| `/l3/m8/ui_state` | `/sil/m8_ui_state`（新增 topic，加入 foxglove whitelist）| 前端 `useFoxgloveLive` |

> **备注**：前端 TOPIC_MAP 中无 `/sil/m8_ui_state`。DEMO-1 验收条件 4 要求 M8 SAT-1 数据流到前端。方案：在 foxglove topic_whitelist 中加入 `/l3/m8/ui_state`，前端增加 handler（归 D1.3.2.3，本 plan 不重复）。或：bridge 将 `/l3/m8/ui_state` 转成 `/sil/module_pulse` 的字段扩展。本 plan 建议前者（最小改动）。

### 1.2 Topic 命名决策原则

1. **SIL 侧 topic 统一 `/sil/*` 前缀** — 前端只消费 `/sil/*`，foxglove whitelist 已限定
2. **L3 侧 topic 保持架构文档 §15.2 定义** — 不修改 L3 内核源码（除 F1-F5 修复）
3. **Bridge 负责所有消息类型转换** — SIL ↔ L3 消息结构不同，bridge 内做字段映射
4. **透传 topic 不经过 bridge** — `/sim_clock`、`/sil/scoring`、`/sil/lifecycle_status` 等已经是正确格式

- [ ] 文档列出全部 12 个 `/sil/*` topic 与 L3 期望 topic 的 1:1 映射
- [ ] 标注需要类型转换的 topic 对（至少 3 对）
- [ ] 标注透传 topic（至少 4 个）

## Task 3: 创建 l3_pipeline.launch.py

**文件：**
- 新建：`src/l3_tdl_kernel/launch/l3_pipeline.launch.py`
- 新建：`src/l3_tdl_kernel/launch/l3_params.yaml`

**职责：** 创建统一的 ROS2 launch 文件，按 M1→M2→M4→M5→M6→M8 依赖顺序启动 L3 内核节点。M7 Safety Supervisor 独立进程并行启动（PATH-S 独立性要求，不可与其他 Doer 共 launch group）。

### 3.1 Launch 文件结构

```python
# src/l3_tdl_kernel/launch/l3_pipeline.launch.py
from launch import LaunchDescription
from launch_ros.actions import Node, LifecycleNode
from launch.actions import DeclareLaunchArgument, GroupAction
from launch.substitutions import LaunchConfiguration

def generate_launch_description():
    params_file = LaunchConfiguration('params_file', default='l3_params.yaml')
    
    declare_params = DeclareLaunchArgument(
        'params_file',
        default_value='l3_params.yaml',
        description='Path to L3 kernel parameters YAML'
    )
    
    # ============================================================
    # Group A: Doer nodes (M1→M2→M4→M5→M6→M8, sequential start)
    # Note: M1-M8 currently use rclcpp::Node (NOT LifecycleNode).
    # LifecycleNode upgrade is deferred to Phase 2 (D2.x).
    # ============================================================
    
    # M1 ODD/Envelope Manager — 调度枢纽，最先启动
    m1_node = Node(
        package='m1_odd_envelope_manager',
        executable='odd_envelope_manager_node',
        name='m1_odd_manager',
        parameters=[params_file],
        output='screen',
    )
    
    # M2 World Model — 依赖 M1 (odd_state)
    m2_node = Node(
        package='m2_world_model',
        executable='world_model_node',
        name='m2_world_model',
        parameters=[params_file],
        output='screen',
    )
    
    # M3 Mission Manager — 依赖 M1 (odd_state) + M2 (world_state)
    m3_node = Node(
        package='m3_mission_manager',
        executable='mission_manager_node',
        name='m3_mission_manager',
        parameters=[params_file],
        output='screen',
    )
    
    # M4 Behavior Arbiter — 依赖 M1+M2+M3
    m4_node = Node(
        package='m4_behavior_arbiter',
        executable='behavior_arbiter_node',
        name='m4_behavior_arbiter',
        parameters=[params_file],
        output='screen',
    )
    
    # M6 COLREGs Reasoner — 依赖 M1+M2
    m6_node = Node(
        package='m6_colregs_reasoner',
        executable='colregs_reasoner_node',
        name='m6_colregs_reasoner',
        parameters=[params_file],
        output='screen',
    )
    
    # M5 Tactical Planner (Mid-MPC) — 依赖 M4+M6
    m5_mid_node = Node(
        package='m5_tactical_planner',
        executable='mid_mpc_node',
        name='m5_tactical_planner',
        parameters=[params_file],
        output='screen',
    )
    
    # M8 HMI/Transparency Bridge — 依赖全部 Doer
    m8_node = Node(
        package='m8_hmi_transparency_bridge',
        executable='hmi_transparency_bridge_node',
        name='m8_hmi_bridge',
        parameters=[params_file],
        output='screen',
    )
    
    # ============================================================
    # Group B: M7 Safety Supervisor — 独立进程，并行启动
    # M7 MUST be in a SEPARATE process (not just separate node)
    # to satisfy Doer-Checker PATH-S independence (§11.6).
    # For DEMO-1, we launch as a separate Node with its own
    # process via a GroupAction. Full OS-process isolation
    # (separate launch file) is deferred to D2.x.
    # ============================================================
    m7_node = Node(
        package='m7_safety_supervisor',
        executable='safety_supervisor_node',
        name='m7_safety_supervisor',
        parameters=[params_file],
        output='screen',
        # Ensure M7 runs after Doer group is up
        # (ROS2 topic discovery will connect regardless of start order)
    )
    
    return LaunchDescription([
        declare_params,
        # Doer group
        m1_node, m2_node, m3_node,
        m4_node, m6_node,
        m5_mid_node, m8_node,
        # Checker (separate process boundary)
        m7_node,
    ])
```

### 5.1 sil_topic_bridge.py

```python
#!/usr/bin/env python3
"""
sil_topic_bridge.py — Bidirectional topic relay between SIL /sil/* namespace
and L3 kernel /fusion/* /l3/m{N}/* namespaces.

Message type conversions:
  SIL own_ship_state (sil_msgs/OwnShipState) ↔ L3 FilteredOwnShipState
  SIL target_vessel_state → L3 TrackedTargetArray
  SIL environment → L3 EnvironmentState
  L3 avoidance_plan → SIL control_cmd
  L3 asdr_record → SIL asdr_event
  L3 module heartbeats → SIL module_pulse (aggregated)

Architecture:
  Runs in sil-nodes container (same DDS domain as sim nodes and L3 nodes).
  Single Python process with MultiThreadedExecutor.
  Zero-copy within same process group (CycloneDDS shared memory).
"""

import sys
import time
import math
from typing import Dict, List, Optional

import rclpy
from rclpy.node import Node
from rclpy.executors import MultiThreadedExecutor
from rclpy.qos import QoSProfile, ReliabilityPolicy, DurabilityPolicy, HistoryPolicy

# SIL message types
from sil_msgs.msg import OwnShipState, TargetVesselState, EnvironmentState
from sil_msgs.msg import ModulePulse, ASDREvent, ScoringRow, LifecycleStatus
from ship_sim_interfaces.msg import ActuatorCmd

# L3 message types
from l3_msgs.msg import (
    ODDState, WorldState, BehaviorPlan, AvoidancePlan,
    COLREGsConstraint, SafetyAlert, ASDRRecord, SATData,
    UIState, ModeCmd, MissionGoal, RouteReplanRequest,
    ReactiveOverrideCmd,
)
from l3_external_msgs.msg import (
    FilteredOwnShipState, TrackedTargetArray, TrackedTarget,
    EnvironmentState as L3EnvState,
)


class SilTopicBridge(Node):
    """Bidirectional bridge between /sil/* and L3 kernel topics."""

    def __init__(self):
        super().__init__('sil_topic_bridge')

        # QoS profiles
        self._sensor_qos = QoSProfile(
            reliability=ReliabilityPolicy.RELIABLE,
            durability=DurabilityPolicy.VOLATILE,
            history=HistoryPolicy.KEEP_LAST,
            depth=5,
        )
        self._event_qos = QoSProfile(
            reliability=ReliabilityPolicy.RELIABLE,
            durability=DurabilityPolicy.TRANSIENT_LOCAL,
            history=HistoryPolicy.KEEP_LAST,
            depth=50,
        )

        # === SIL → L3 bridges ===

        # own_ship_state: SIL flat → L3 FilteredOwnShipState
        self._sub_own_ship = self.create_subscription(
            OwnShipState, '/sil/own_ship_state',
            self._on_own_ship_state, self._sensor_qos)
        self._pub_fusion_own = self.create_publisher(
            FilteredOwnShipState, '/fusion/own_ship_state', self._sensor_qos)

        # target_vessel_state: SIL flat → L3 TrackedTargetArray
        self._sub_targets = self.create_subscription(
            TargetVesselState, '/sil/target_vessel_state',
            self._on_target_vessel_state, self._sensor_qos)
        self._pub_fusion_targets = self.create_publisher(
            TrackedTargetArray, '/fusion/tracked_targets', self._sensor_qos)

        # environment: SIL → L3 (字段名略有不同，但结构兼容)
        self._sub_env = self.create_subscription(
            EnvironmentState, '/sil/environment',
            self._on_environment, self._sensor_qos)
        self._pub_fusion_env = self.create_publisher(
            L3EnvState, '/fusion/environment_state', self._sensor_qos)

        # === L3 → SIL bridges ===

        # avoidance_plan → control_cmd
        self._sub_avoidance = self.create_subscription(
            AvoidancePlan, '/l3/m5/avoidance_plan',
            self._on_avoidance_plan, self._sensor_qos)
        self._pub_control_cmd = self.create_publisher(
            ActuatorCmd, '/sil/control_cmd', self._sensor_qos)

        # asdr_record → asdr_event
        self._sub_asdr = self.create_subscription(
            ASDRRecord, '/l3/asdr/record',
            self._on_asdr_record, self._event_qos)
        self._pub_asdr_event = self.create_publisher(
            ASDREvent, '/sil/asdr_event', self._event_qos)

        # M8 ui_state → sil/m8_ui_state (for frontend)
        self._sub_ui = self.create_subscription(
            UIState, '/l3/m8/ui_state',
            self._on_ui_state, self._sensor_qos)
        self._pub_ui = self.create_publisher(
            UIState, '/sil/m8_ui_state', self._sensor_qos)

        # Module pulse aggregator
        # Collect heartbeats from M1-M8 and publish aggregated /sil/module_pulse
        self._module_last_seen: Dict[str, float] = {}
        self._module_subscribers = self._setup_module_heartbeat_subs()
        self._pub_module_pulse = self.create_publisher(
            ModulePulse, '/sil/module_pulse', self._sensor_qos)
        self._module_pulse_timer = self.create_timer(1.0, self._publish_module_pulse)

        self.get_logger().info('SIL Topic Bridge initialized (7 bridges active)')

    # ---------- SIL → L3 converters ----------

    def _on_own_ship_state(self, msg: OwnShipState):
        """Convert SIL flat OwnShipState to L3 FilteredOwnShipState."""
        out = FilteredOwnShipState()
        out.header.stamp = self.get_clock().now().to_msg()
        out.header.frame_id = 'map'
        out.pose_lat = msg.lat
        out.pose_lon = msg.lon
        out.heading_rad = math.radians(msg.heading)
        out.sog_mps = msg.sog * 0.5144  # kn → m/s
        out.cog_rad = math.radians(msg.cog)
        out.rot_rps = msg.rot
        out.surge_mps = msg.u
        out.sway_mps = msg.v
        out.yaw_rate_rps = msg.r
        # DEMO-1: covariance set to identity (no real EKF)
        out.covariance = [1.0 if i % 7 == 0 else 0.0 for i in range(49)]
        out.confidence = 0.9
        self._pub_fusion_own.publish(out)

    def _on_target_vessel_state(self, msg: TargetVesselState):
        """Convert SIL flat TargetVesselState to L3 TrackedTargetArray."""
        out = TrackedTargetArray()
        out.header.stamp = self.get_clock().now().to_msg()
        out.header.frame_id = 'map'
        target = TrackedTarget()
        target.target_id = msg.mmsi
        target.pose_lat = msg.lat
        target.pose_lon = msg.lon
        target.heading_rad = math.radians(msg.heading)
        target.sog_mps = msg.sog * 0.5144
        target.cog_rad = math.radians(msg.cog)
        target.classification = 0  # unknown
        target.confidence = 0.85
        out.targets = [target]
        self._pub_fusion_targets.publish(out)

    def _on_environment(self, msg: EnvironmentState):
        """Forward SIL environment to L3 format."""
        out = L3EnvState()
        out.header.stamp = self.get_clock().now().to_msg()
        out.wind_speed_mps = msg.wind_speed_kn * 0.5144
        out.wind_direction_rad = math.radians(msg.wind_direction_deg)
        out.current_speed_mps = msg.current_speed_kn * 0.5144
        out.current_direction_rad = math.radians(msg.current_direction_deg)
        out.visibility_m = msg.visibility_m
        out.sea_state = 0  # DEMO-1: calm
        out.confidence = 0.9
        self._pub_fusion_env.publish(out)

    # ---------- L3 → SIL converters ----------

    def _on_avoidance_plan(self, msg: AvoidancePlan):
        """Convert L3 AvoidancePlan to SIL ActuatorCmd."""
        out = ActuatorCmd()
        out.header.stamp = self.get_clock().now().to_msg()
        # Extract first waypoint's rudder and speed from avoidance plan
        if msg.waypoints and len(msg.waypoints) > 0:
            wp = msg.waypoints[0]
            out.rudder_angle_deg = wp.rudder_angle_deg if hasattr(wp, 'rudder_angle_deg') else 0.0
            out.throttle = wp.throttle if hasattr(wp, 'throttle') else 0.5
            out.target_speed_kn = wp.target_speed_kn if hasattr(wp, 'target_speed_kn') else 0.0
        out.rpm = 0.0  # DEMO-1: computed by ship_dynamics from throttle
        out.pitch = 0.0
        self._pub_control_cmd.publish(out)

    def _on_asdr_record(self, msg: ASDRRecord):
        """Forward L3 ASDRRecord to SIL ASDREvent."""
        out = ASDREvent()
        out.header.stamp = self.get_clock().now().to_msg()
        out.event_id = msg.record_id if hasattr(msg, 'record_id') else 0
        out.module_id = msg.module_id if hasattr(msg, 'module_id') else 'unknown'
        out.event_type = msg.event_type if hasattr(msg, 'event_type') else 'decision'
        out.payload = msg.decision_summary if hasattr(msg, 'decision_summary') else ''
        self._pub_asdr_event.publish(out)

    def _on_ui_state(self, msg: UIState):
        """Forward M8 UI state to /sil/ namespace for frontend."""
        self._pub_ui.publish(msg)

    # ---------- Module pulse aggregator ----------

    def _setup_module_heartbeat_subs(self):
        """Subscribe to M1-M8 heartbeat topics."""
        modules = {
            'm1_odd_manager': '/l3/m1/odd_state',
            'm2_world_model': '/l3/m2/world_state',
            'm3_mission_manager': '/l3/m3/mission_goal',
            'm4_behavior_arbiter': '/l3/m4/behavior_plan',
            'm5_tactical_planner': '/l3/m5/avoidance_plan',
            'm6_colregs_reasoner': '/l3/m6/colregs_constraint',
            'm7_safety_supervisor': '/l3/m7/heartbeat',
            'm8_hmi_bridge': '/l3/m8/ui_state',
        }
        subs = []
        for mod_name, topic in modules.items():
            def make_callback(name):
                def cb(msg):
                    self._module_last_seen[name] = time.time()
                return cb
            sub = self.create_subscription(
                # Use generic AnyMsg or import specific types
                # For simplicity, subscribe to raw messages
                type(self).__bases__[0],  # fallback — use appropriate msg type
                topic,
                make_callback(mod_name),
                self._sensor_qos,
            )
            subs.append(sub)
        return subs

    def _publish_module_pulse(self):
        """Publish aggregated module health pulse."""
        now = time.time()
        out = ModulePulse()
        out.header.stamp = self.get_clock().now().to_msg()
        # Report which modules are active
        out.module_ids = []
        out.is_active = []
        for mod_id, last_seen in sorted(self._module_last_seen.items()):
            out.module_ids.append(mod_id)
            out.is_active.append((now - last_seen) < 5.0)  # alive if seen in last 5s
        if out.module_ids:
            self._pub_module_pulse.publish(out)


def main():
    rclpy.init()
    bridge = SilTopicBridge()
    executor = MultiThreadedExecutor(num_threads=2)
    executor.add_node(bridge)
    try:
        print('[sil_topic_bridge] Bridge active — relaying /sil/* ↔ L3 kernel')
        executor.spin()
    except KeyboardInterrupt:
        pass
    finally:
        executor.shutdown()
        bridge.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

```bash
#!/bin/bash
# verify_demo1_e2e.sh — DEMO-1 end-to-end verification script
#
# Usage: bash scripts/verify_demo1_e2e.sh [--timeout 120]
#
# Verifies:

#   2. /sil/own_ship_state publishing at ~50 Hz
#   3. /l3/m2/world_state publishing (M2 active)
#   4. /l3/m4/behavior_plan publishing (M4 IvP active, stub output OK)
#   5. /l3/m5/avoidance_plan publishing (M5 MPC active, stub output OK)
#   6. /sil/control_cmd publishing (bridge relay active)
#   7. /sil/module_pulse publishing (bridge aggregator active)
#   8. /sil/m8_ui_state publishing (M8 SAT-1 bridge active)
#
# Exit 0 = all checks pass, Exit 1 = any check fails

set -euo pipefail

TIMEOUT=120
CONTAINER="mass-l3-sil-nodes-1"

while [[ $# -gt 0 ]]; do
    case $1 in
        --timeout) TIMEOUT="$2"; shift 2 ;;
        --container) CONTAINER="$2"; shift 2 ;;
        *) echo "Unknown arg: $1"; exit 2 ;;
    esac
done

RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
NC='\033[0m'

PASS=0
FAIL=0

check() {

    local cmd="$2"
    local expected="$3"

    local result
    result=$(docker compose exec -T "$CONTAINER" bash -c "source /opt/ros/humble/setup.bash && source /opt/ws/install/setup.bash && $cmd" 2>&1) || true
    if echo "$result" | grep -q "$expected"; then
        echo -e "${GREEN}PASS${NC}"
        ((PASS++))
    else
        echo -e "${RED}FAIL${NC}"
        echo "    Expected: $expected"
        echo "    Got:      ${result:0:200}"
        ((FAIL++))
    fi
}

echo "============================================"
echo " DEMO-1 End-to-End Verification"
echo " Container: $CONTAINER"
echo " Timeout:   ${TIMEOUT}s"
echo "============================================"

# Wait for nodes to come up
echo ""
echo "[1/2] Waiting for SIL+L3 nodes to initialize (${TIMEOUT}s max)..."

    fi
    echo "  $NODE_COUNT nodes (need ≥16) ... waiting 5s"
    sleep 5
    ELAPSED=$((ELAPSED + 5))
done

if [ "$NODE_COUNT" -lt 16 ]; then
    echo -e "${RED}FAIL: Only $NODE_COUNT nodes after ${TIMEOUT}s (need ≥16)${NC}"
    docker compose exec -T "$CONTAINER" bash -c "source /opt/ros/humble/setup.bash && source /opt/ws/install/setup.bash && ros2 node list" 2>/dev/null || true
    exit 1
fi

echo ""
echo "[2/2] Running verification checks..."

# Check 1: 7 L3 nodes present
check "L3 M1 ODD Manager" \
    "ros2 node list | grep m1_odd_manager" \
    "m1_odd_manager"

check "L3 M2 World Model" \
    "ros2 node list | grep m2_world_model" \
    "m2_world_model"

check "L3 M4 Behavior Arbiter" \
    "ros2 node list | grep m4_behavior_arbiter" \
    "m4_behavior_arbiter"

check "L3 M5 Tactical Planner" \
    "ros2 node list | grep m5_tactical_planner" \
    "m5_tactical_planner"

check "L3 M6 COLREGs Reasoner" \
    "ros2 node list | grep m6_colregs_reasoner" \
    "m6_colregs_reasoner"

check "L3 M7 Safety Supervisor" \
    "ros2 node list | grep m7_safety_supervisor" \
    "m7_safety_supervisor"

check "L3 M8 HMI Bridge" \
    "ros2 node list | grep m8_hmi_bridge" \
    "m8_hmi_bridge"

# Check 2: SIL sim topics alive
check "/sil/own_ship_state publishing" \
    "ros2 topic hz /sil/own_ship_state --window 3 2>&1 | grep 'average rate'" \
    "average rate"

# Check 3: L3 internal topics alive
check "/l3/m2/world_state publishing" \
    "ros2 topic hz /l3/m2/world_state --window 3 2>&1 | grep 'average rate'" \
    "average rate"

check "/l3/m4/behavior_plan publishing" \
    "ros2 topic hz /l3/m4/behavior_plan --window 3 2>&1 | grep 'average rate'" \
    "average rate"

check "/l3/m5/avoidance_plan publishing" \
    "ros2 topic hz /l3/m5/avoidance_plan --window 3 2>&1 | grep 'average rate'" \
    "average rate"

# Check 4: Bridge topics alive
check "/sil/control_cmd publishing (bridge)" \
    "ros2 topic hz /sil/control_cmd --window 3 2>&1 | grep 'average rate'" \
    "average rate"

check "/sil/module_pulse publishing (bridge)" \
    "ros2 topic hz /sil/module_pulse --window 3 2>&1 | grep 'average rate'" \
    "average rate"

check "/sil/m8_ui_state publishing (bridge)" \
    "ros2 topic hz /sil/m8_ui_state --window 3 2>&1 | grep 'average rate'" \
    "average rate"

# Summary
echo ""
echo "============================================"
echo -e " Results: ${GREEN}$PASS passed${NC}, ${RED}$FAIL failed${NC}"
echo "============================================"

if [ "$FAIL" -gt 0 ]; then
    echo ""
    echo "=== Diagnostic: node list ==="
    docker compose exec -T "$CONTAINER" bash -c "source /opt/ros/humble/setup.bash && source /opt/ws/install/setup.bash && ros2 node list" 2>/dev/null || true
    echo ""
    echo "=== Diagnostic: topic list ==="
```
