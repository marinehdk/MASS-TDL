## 1. 执行摘要

D1.3.2.3 的任务是用 MapLibre GL JS 替换静态 SVG 雷达原型，通过 ENC MVT 瓦片层 + foxglove_bridge WebSocket 提供生产级 SIL HMI，满足 DEMO-1 (6/15) 的船长视角展示需求。

**当前状态**: React 18 + TypeScript + Vite + MapLibre GL JS 4.x 前端已上线。foxglove_bridge (port 8765, JSON 模式) 与 FastAPI `/ws/sil_debug` (port 8000) 双通道数据流已实现。6 项 Playwright e2e 测试已编写。ENC 瓦片管线通过 Martin tile server 提供 trondheim + sfbay 两区域数据。DEMO MODE 红标 UI 已落地。

### Task 3: foxglove_bridge install + launch file ✅

**容器**: `foxglove-bridge-1` (image: `mass-l3/ci:humble-ubuntu22.04`, port 8765)

**数据流架构**:
```
ROS2 DDS domain → foxglove_bridge (C++, JSON mode) → ws://localhost:8765
                                                           ↓
FastAPI /ws/sil_debug (port 8000) → 决策/场景管理数据
```

**前端消费**: `hooks/useFoxgloveLive.ts` — WebSocket 连接到 foxglove_bridge，订阅以下 topic:
- `/sil/own_ship_state` → ConningBar (SOG, COG, HDG, ROT)
- `/sil/target_vessel_state` → ThreatRibbon (CPA/TCPA chips)
- `/sil/module_pulse` → ModulePulseBar (M1-M8 heartbeat dots)
- `/sil/m8_ui_state` → SAT-1 透明性数据
- `/sil/scoring` → ScoringRow

**demo_telemetry fallback**: `hooks/useDemoTelemetry.ts` 提供 demo 模式下的模拟遥测数据。当前 `SimulationMonitor.tsx` 同时运行 `useFoxgloveLive()` 和 demo fallback，确保在 foxglove_bridge 未连接时 UI 不空白。

### Task 6: foxglove_bridge → React data flow ✅

**`hooks/useFoxgloveLive.ts`** (主数据流 hook):

```typescript
// WebSocket 订阅 foxglove_bridge
// 订阅 11 个 /sil/* topic:
//   own_ship_state, target_vessel_state, environment,
//   module_pulse, scoring, lifecycle_status,
//   m8_ui_state, asdr_event, control_cmd, sim_clock
//
// 三层节流:
//   ROS2 topic_tools (50→10Hz) + Protobuf (DEMO-2) + React rAF (always)
```

**数据到达 UI 组件前经过的链路**:
```
foxglove_bridge WS → JSON parse → TOPIC_MAP lookup
→ React state (useFoxgloveLive) → props → ConningBar/ThreatRibbon/ModulePulseBar
```

**demo_telemetry 旁路**: 当 `useFoxgloveLive` 返回 `isLive=false` 时，`useDemoTelemetry` 接管，注入预录轨迹数据。`SimulationMonitor.tsx:428` 在 demo 模式下显示红标警告。

## 4. ENC Raster Tile 加载验证

### 4.1 Trondheim 区域 (63.44°N, 10.38°E)

- **数据源**: S-57 ENC (Norwegian Hydrographic Service)
- **瓦片服务**: Martin tile server (`martin-tile-server-1:3000`)
- **验证方式**: `SimulationMonitor.tsx` URL `/#/monitor/imazu-08` 自动居中到 Trondheim。MapLibre 向 Martin 请求 `{z}/{x}/{y}` MVT 瓦片。

### 4.2 SF Bay 区域 (37.8°N, 122.4°W)

- **数据源**: S-57 ENC (NOAA)
- **瓦片服务**: 同 Martin tile server
- **验证方式**: `SimulationScenario.tsx` 场景编辑模式支持平移至 SF Bay

### 4.3 Fallback 机制

当 Martin tile server 不可用时 (`map/layers.ts:38`)，MapLibre 使用内置的 S-57 简化海图层。`ContainerSpecPanel.tsx` 显示 Martin Server 在线状态（gateId: 1），`QuickFixPanel.tsx` 提供一键重启按钮。

## 5. DEMO MODE 红标 UI

**位置**: `SimulationMonitor.tsx:428`

**触发条件**: URL hash 包含 `?dev=1` 或 foxglove_bridge 未连接。

**渲染内容**:
```tsx
<div style={{ background: '#8B0000', color: '#fff', padding: '4px 12px', 
     fontFamily: 'Saira Condensed', fontWeight: 600, fontSize: 13 }}>
  DEMO MODE — dead-reckon fallback
</div>
```

**语义**: 红底白字（`#8B0000` dark red 背景）表示当前 HMI 显示的是死推导航 fallback 数据，非实时 ROS2 遥测。`useDemoTelemetry.ts` 提供 10 Hz 模拟轨迹（沿预设航线匀速直行，无避碰动作）。
