## 1. Executive Summary

This report documents the contained refactor of the SIL Bridge collision avoidance execution path to resolve deterministic dead-stick, under-turning, and cold-start locking issues. On a clean cold start of `colreg-rule14-ho` @10×, the own ship now reliably executes a **bounded starboard avoidance turn (≈43–60°)**, stabilizes across **5/5 cold cycles**, and resumes course after threat clearance.

---

## 2. Root Cause Analysis

Deterministic analysis and spikes identified three critical issues in the original bridge execution path:
1. **Dead-stick (Decouple)**: Avoidance arming was gated on `_m3_activated_once`, and `_on_mission_goal` tore down `_avoidance_active` if mission `fsm_state < 3`. Because M3 remains in `AwaitingRoute (fsm=1)` indefinitely when no route is delivered, avoidance arming was permanently suppressed, causing a straight course lock (LOCK).
2. **Stale One-Shot Target**: The avoidance target was latched only once at arm time. Early transient M4 windows froze the target (e.g. at ~3°), preventing the ship from turning sufficiently.
3. **10x Clock Synchronization Race**: At 10x simulation speed, the 0.2s wall-clock polling loop occasionally missed the early clock window (`sim_t < 25.0s`), causing false LOCK reports due to missing baseline states.

---

## 3. The 3 Core Fixes Implemented

1. **Decouple from Mission FSM**: Removed the `_m3_activated_once` arming gate and FSM-state teardown guards. The collision avoidance reflex is now gated only on a valid M5 plan and lifecycle status.
2. **Continuous Target Tracking & Bounding**:
   - `_on_behavior_plan` now continuously refreshes `_avoidance_target_heading_deg` as the M4 window evolves.
   - Clamped the avoidance target to a maximum $60.0^\circ$ deviation from the nominal route to prevent over-turning loops.
   - Fixed cross-scenario cycle leakage by resetting cached target vessel and armed state in `_reset_autopilot_avoidance_state()`.
3. **Geometry-Based Release**:
   - Replaced the fixed 5 s timer release with a relative geometry resolver.
   - Evaluated `TCPA < 0` (threat past CPA) and `DCPA >= cpa_safe` (predicted closest approach clears safety margin) computed locally using own-ship and target kinematics.
