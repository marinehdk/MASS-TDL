1. **C1 航路接收**：mock L2 在 `/route_planning/gnc_route_plan` 发 `GncRoutePlan`，L3 侧订阅器收到并入库；**再发一条新 `GncRoutePlan` → 内部航路被替换**（重入验证）。

## 5. 组件 B — 运行时目标注入

### B1. 几何生成器（后端 Python · 本期复用核心）
纯函数 `generate_encounter(rule, R_nm, construct_cpa_m, beta_deg|None, ownstate) → TargetSpawn{mmsi,lat,lon,course_deg,sog_kn}`。本船态 `ownstate=(P0,ψ0,v0)` 取自 bridge 缓存 `_last_ownship_raw`（`docker/sil_topic_bridge.py:689`，已核实）。

**构造法（CBDR 碰撞瞄准，[R6]）**：本地平面 ENU 围 P0（1 NM=1852 m；dlat=N/111120，dlon=E/(111120·cosφ₀)）。
- 目标生成点 `S = P0 + R·(sin(ψ0+B_rel), cos(ψ0+B_rel))`。
- 取 CPA 时刻 T，本船未来点 `Po(T)=P0+v_o·T`；目标速度矢 `v_t=(Po(T)+d_cpa·n̂ − S)/T`，`n̂`⊥本船航向 → 航向/航速由此出。`construct_cpa_m=0` → 碰撞航线（强制系统机动）。

**逐规则参数**（默认值已锁）：

| Rule | B_rel(生成相对方位) | target 速度策略 | 航向构造 | 默认 R / construct_cpa |
|---|---|---|---|---|
| **R14 对头** `head_on` | 0°(正前) | =v0 | 对称 T → reciprocal(ψ0+180) | 1.5 NM / 0 m |
| **R15 让路** `crossing_giveway` | +45°(右舷前) | =v0 | CBDR 瞄准 + 横移 | 2.0 NM / 300 m |
| **R15 直航** `crossing_standon` | −45°(左舷前) | =v0 | CBDR 瞄准 + 横移 | 2.0 NM / 300 m |
| **R13 追越** `overtaking` | 0°(正前) | =0.5·v0 | =ψ0(同向慢船) | 1.0 NM / 200 m |

> **术语去歧**（直击上会话 COLREGs 评审缺口 [R4]）：`construct_cpa_m`=**生成几何的初始 CPA**（建多近的逼近），≠`required_cpa_m`=**避碰须达到的通过距离**（合格判据，测试台用，默认 500 m）。判合格看 outcome CPA 不看 construct CPA。

### B2. AddTarget / RemoveTarget service（target_vessel_node）
- 新 srv `sil_msgs/AddTarget`(req: `mmsi,lat,lon,heading_deg,sog_kn,mode`; resp: `success,message`) + `RemoveTarget`(req: `mmsi`; resp: `removed`)。
- ACTIVE 中调用：`add_target()` 向活动 `self._targets` 追加，下个 tick 即步进发布（list-step 已支持，`src/sim_workbench/sil_nodes/target_vessel/target_vessel/node.py:153/176/276` 核实）。`RemoveTarget` / 清空供注入间复位。

### B3. Orchestrator REST
```
POST /api/v1/encounters/inject
  body {rule:"head_on"|"crossing_giveway"|"crossing_standon"|"overtaking",
        range_nm?:float, construct_cpa_m?:float, approach_angle_deg?:float}
  → 读缓存本船态 → generate_encounter → AddTarget srv → {accepted:bool, mmsi:int}
  409 若 sim 非 ACTIVE / 本船态不可用
DELETE /api/v1/encounters/{mmsi} → RemoveTarget → {removed:bool}
DELETE /api/v1/encounters       → 清除全部注入船
```
仿现有 `/api/v1/fault/inject` stub 形（`web/src/api/silApi.ts`）。

## 7. 降级 / 边界路径（§6 完成判据）

| 条件 | 行为 |
|---|---|
| L2 航路未收到/空 | 海图提示"等待 L2 航路"；sim 仍可跑 `nominalRoute` 兜底 |
| 注入时 sim 非 ACTIVE | REST 409，面板提示"先启动仿真" |
| 本船态缺失/陈旧(>2s) | REST 409，"本船态不可用，稍候" |
| 重复注入 | 允许叠加（多船）；"清除注入船"复位 |
| OUT-of-ODD | M1 ODD 仍为唯一权威；注入**不旁路** ODD/安全语境（ADR-1）；几何落 ODD 假设外仅记日志 |
