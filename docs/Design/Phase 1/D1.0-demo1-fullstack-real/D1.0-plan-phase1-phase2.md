### Sub-task 6.1: tracker_mock — CPA/TCPA 计算

- [ ] **Step 1: 编写 CPA/TCPA 计算函数**

在 `tracker_mock/node.py` 中新增 `compute_cpa_tcpa()` 函数：

```python
def compute_cpa_tcpa(own_pos, own_sog, own_cog, tgt_pos, tgt_sog, tgt_cog):
    own_vx = own_sog * math.sin(math.radians(own_cog))
    own_vy = own_sog * math.cos(math.radians(own_cog))
    tgt_vx = tgt_sog * math.sin(math.radians(tgt_cog))
    tgt_vy = tgt_sog * math.cos(math.radians(tgt_cog))
    dx = tgt_pos[0] - own_pos[0]
    dy = tgt_pos[1] - own_pos[1]
    dvx = tgt_vx - own_vx
    dvy = tgt_vy - own_vy
    tcpa = -(dx * dvx + dy * dvy) / (dvx**2 + dvy**2 + 1e-9)
    tcpa = max(tcpa, 0.0)
    cpa_x = dx + dvx * tcpa
    cpa_y = dy + dvy * tcpa
    cpa = math.sqrt(cpa_x**2 + cpa_y**2)
    return cpa, tcpa
```

- [ ] **Step 2: 编写 encounter 分类函数**

在 `tracker_mock/node.py` 中新增 `classify_encounter()` 函数：

```python
def classify_encounter(relative_bearing_deg, aspect_angle_deg, cpa_m, tcpa_s):
    if tcpa_s <= 0 or cpa_m > 3000:
        return 0  # NONE
    rb = relative_bearing_deg % 360
    if 112.5 <= rb <= 247.5:
        return 1  # OVERTAKING
    if 0 <= rb < 22.5 or 337.5 <= rb <= 360 or (345 <= rb <= 360):
        return 2  # HEAD_ON
    if 22.5 <= rb < 112.5:
        return 3  # CROSSING_GIVE_WAY
    if 247.5 <= rb < 345:
        return 4  # CROSSING_STAND_ON
```
