#!/bin/bash

errors=0

done

if [ $errors -eq 0 ]; then

else
  echo "FAILED: $errors compliance issues found"

fi

## 10. 风险与应对

| ID | 风险 | 概率 | 影响 | Contingency |
|---|---|---|---|---|
| R1 | `uint16 schema_version` 在 DDS 序列化时与下游（L2/L4/L5/Fusion）期望的 `string` 类型不兼容 | 🟡 中 | 跨层集成失败 | 在下游 IDL stub 中也改 uint16；或用 ros2 interface show 提前对齐。DEMO-1 仅需内部 mock → 影响有限 |
